## M-01 Просмотреть список в карточках или таблице

Уточнения3–4ноября2026 и текущая реализация соответствия двух видов, девяти каталожных объектов и немедленной фильтрации по типу/статусу ведутся в [контракте каталога](<../../../specs/Разделы/Метрики и показатели/Контракт.md>). При входе без metricView открывается таблица; явный cards и ручной выбор сохраняют свой вид.

Вход — самостоятельный каталог либо связанные метрики выбранного отчёта. Наборы различаются: девять каталожных объектов и десять связей каждого из двух установленных report-fixture. В обоих контекстах карточки/таблица показывают те же сущности своего набора; одиночные тип/статус немедленно пересекают условия без общей кнопки Apply. Поиск по названию/домену/формуле реализован только во вкладке отчёта. Размещение такого поиска в самостоятельном каталоге остаётся неустановленным; новое поле не добавляется по аналогии. Статические заголовки метрик не получают меню отчётных колонок.

URL каталога хранит `metricView`, `metricType`, `metricStatus`; вкладка отчёта — `relatedMetricView`, `relatedMetricQuery`, `relatedMetricType`, `relatedMetricStatus`, `relatedMetricPage`. Поиск, тип и статус связанных метрик возвращают первую страницу; смена вида сохраняет страницу. Возврат из паспорта и reload сохраняют этот контекст по контракту раздела; межсессионное серверное хранение этим не заявляется. MagicPath, область4 сохраняет исторический пользовательский указатель и пакет; его клики не доказывают нативную Figma или backend.

## M-02 Открыть и изучить полный показатель

Расширение3ноября: по поручению пользователя добавлено открытие собственного объекта из самостоятельного каталога в обоих видах. По прямому решению4ноября любой объект обоих списков открывает собственный полный паспорт с12 секциями; у исходного4 сохраняется Figma-содержание, у остальных разрешены отдельные demo-примеры. Композиция, происхождение данных и правила возврата ведутся в [контракте раздела](<../../../specs/Разделы/Метрики и показатели/Контракт.md>). Описание входа из исходной записи ниже сохраняет историческое основание и не ограничивает новое расширение.

**Вход:** выбран связанный показатель в отчёте. В исходной записи показан путь именно из вкладки отчёта, не доказан клик из любого самостоятельного списка.

1. Пользователь открывает полный показатель; сохраняется идентичность объекта.
2. Изучает паспорт, определение с условиями/исключениями, методику и отдельную формулу. Пустые бизнес-вопросы не заполняются вымыслом.
3. Изучает подтверждённые связи. Наличие строки связи не подтверждает реализацию её отвязки или открытие внешнего инструмента.
4. Может увидеть форму вопроса; успешная отправка, права, модерация и сохранение не подтверждены.

Прямое поручение требует адаптировать паттерны отчёта к собственным полям показателя. Платформа, мастер-системы и чувствительность из отчётного паспорта не копируются автоматически. Краткое определение перенесено в подсказку иконки, полная формулировка остаётся в содержимом; правило ведётся у [Target](<../Требования/Карточки.md#полная-карточка-показателя--определение-в-подсказке-решение-28-октября>). Поздние запросы аккордеонов и коротких пояснений нельзя считать выполненными по старому снимку 28 октября.

**Результат/проверка:** [нативный паспорт](https://www.figma.com/design/lnOcWh4ElGkhppWe6Kn5AA/Untitled?node-id=1147-30852), проверенная исходная сборка, ограничения поздней версии. Состав и layout проверены для конкретной версии, Present и продуктовый backend — нет. Два синтетических варианта MagicPath являются визуальными предложениями, не выбранным контрактом взаимодействия.

**Выход:** прототип возвращает в исходный список/отчёт с видом и фильтрами, в том числе после reload паспорта; прямой URL без истории возвращает в каталог. Каталог сохраняет позицию в текущем просмотре. Восстановление фокуса/позиции при произвольном выходе, редактирование, отвязка, серверное сохранение избранного и реальная отправка вопроса остаются ограничениями. Админку пользователь исключил из текущего объёма; новых редакторов этот документ не вводит.
