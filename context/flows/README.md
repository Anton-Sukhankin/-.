# Целевые пользовательские пути

Экспорт связанного владельца для передачи frontend-разработчику. Архивные свидетельства не включены; условия, статусы и неизвестные сохранены. Для конкретного вида и состояния сначала читать принятый контракт в `specs/`.

Срез сверки: 29 октября 2026. Здесь ведутся последовательности действий и целевые UI-результаты. Исходные наблюдения остаются в Current, требования и границы — у [владельца решений](<../requirements.md>), поля — в [реестре карточек](<../data-attributes.md>). Существование экрана не подтверждает внедрение в сервисе.

| Задача | Основной маршрут | Граница |
|---|---|---|
| Главная, избранное, подписки, вклад, новости | [Главная](<home.md>) | Разделы и виды не смешиваются с самостоятельным каталогом |
| Каталог, полный отчёт, вопросы и рассылки | [Отчёты](<reports.md>) | Внешние действия и админка имеют отдельные границы |
| Общая панель и синхронизация фильтров отчётных списков | [Фильтрация отчётов](<filters.md>) | Показанная демо-комбинация не равна полной серверной фильтрации |

Новые ссылки добавляются после создания и проверки соответствующего документа. Один переход описывается у одного владельца, остальные разделы передают контекст ссылкой. Права, внешние результаты и сохранение без оснований остаются неизвестными.

Для сценария фиксируются цель/вход, действия и результаты, значимые состояния, выход/возврат, отличие от Current, основания и границы проверки. Согласовано, нарисовано, реакции настроены и взаимодействие выполнено — разные уровни. Изменение решения требует проверки связанных сценариев; одна новая картинка сама по себе не отменяет принятое правило.

Остальные разделы вне объёма этой передачи; назначения переходов не являются поручением реализовать их внутренние страницы.
