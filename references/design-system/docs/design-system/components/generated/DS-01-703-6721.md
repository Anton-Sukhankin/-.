## Поиск и настройка INSTANCE

1. Найти `DS-01:component:703:6721` через `scripts/find_design_context.py` с `--details` и точным `--property 'имя=значение'` из definition. Открыть только запись выбранного варианта, его обязательные зависимости и визуальный фрагмент.
2. Проверить sourceRole, ограничения и статус независимой проверки. Вставить настоящий INSTANCE выбранного COMPONENT по его key; затем сверить полученный main component, варианты и полный источник.
3. Настраивать объявленные BOOLEAN/TEXT/INSTANCE_SWAP свойства по точным именам. Для варианта выбирать только существующее сочетание; при изменении текста/слота сверять geometry, перенос, clipping и родительский layout.
4. Для нужного режима сверить фактически применённые variables/styles и отличия исходного состояния. Маски, допустимые overrides, интеракции и адаптивность не дополняются предположением; зависимое применение ждёт конкретного доказательства.
5. Проверить результат отдельного применения по порядку работы в Figma; подготовка этой карточки не выполняет и не принимает пилот A7.
