## Назначение и граница

**Наблюдаемое устройство:** Однострочное поле с внешней подписью, маркером обязательности, строкой ввода и описанием.

Основание: Исходник 418:2000; точная схема и ближайшая структура default сохранены в families-*.json, чтение 29.09.2026.

Основание: Адресное read-only чтение 04.10.2026: evidence/air-kit/implementation-checks/status-button-input-2026-10-04/; исторические исходники сохранены.

Анатомия: label → Label и *, Input → левый значок, Value wrapper и правый значок; ниже Description. На исходном листе enabled содержит бледный Value, active — текстовый caret, active+ — введённый Val, valid — заполненный Value; invalid выделяет рамку и описание красным, disabled ослабляет содержимое. Это наблюдение 14 статических вариантов, не алгоритм валидации.
Read-only сверка 04.10.2026: 14 вариантов, семь состояний и два размера, пять BOOLEAN состава; TEXT/SLOT/INSTANCE_SWAP отсутствуют. В active значение буквально |Value, в active+ — Va|. Root 320×96 для M и 320×88 для S; PNG 320×97/89 включает нижнюю растеризацию текста description. В части source Wrapper записан paddingTop/paddingBottom=71 при иной фактической позиции детей; это наблюдение сохранено, не общее правило padding. Identity, native-геометрия и 14 PNG.

Обязательный владелец авторских изменений и публикации: [указания и незавершённые решения](<../../research/air-kit.md#авторские-указания-и-незавершённые-решения>). ## Поиск и настройка INSTANCE

1. Найти `DS-01:component:418:2000` через `scripts/find_design_context.py` с `--details` и точным `--property 'имя=значение'` из definition. Открыть только запись выбранного варианта, его обязательные зависимости и визуальный фрагмент.
2. Проверить sourceRole, ограничения и статус независимой проверки. Вставить настоящий INSTANCE выбранного COMPONENT по его key; затем сверить полученный main component, варианты и полный источник.
3. Настраивать объявленные BOOLEAN/TEXT/INSTANCE_SWAP свойства по точным именам. Для варианта выбирать только существующее сочетание; при изменении текста/слота сверять geometry, перенос, clipping и родительский layout.
4. Для нужного режима сверить фактически применённые variables/styles и отличия исходного состояния. Маски, допустимые overrides, интеракции и адаптивность не дополняются предположением; зависимое применение ждёт конкретного доказательства.
5. Проверить результат отдельного применения по порядку работы в Figma; подготовка этой карточки не выполняет и не принимает пилот A7.

## Неизвестное и ограничения

- Курсор в исходном состоянии — иллюстрация, не нативный caret. Редактируемые value/label/description, произвольные React-иконки и валидация потребителя являются инженерным API; обычные FRAME не объявляются source SLOT. Усечение, семантика required и ошибки проверяются по отдельному контракту реализации.
- Область независимой визуальной проверки задаёт внешний протокол приёмки. Иные темы и разрешённые overrides требуют отдельного доказательства; исходные размеры не подтверждают новые контейнеры.
- Схема и изображение не доказывают опубликованную версию, runtime-логику, доступность или продуктовые условия применения.
- Изменение source/component/variable/style требует адресной перепроверки этой карточки и связанных потребителей по каталогу.

Владелец сгенерированных фактов — нормализованный исходник; предметные пояснения — air-kit-component-guidance.json. Генератор `scripts/build_air_kit_components.py` не присваивает статус accepted. Карточку вручную не редактируют.
