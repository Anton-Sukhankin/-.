# Поручение агенту фронтенда

1. Найдите поручённый экран в [оглавлении](README.md). Прочтите его композицию, состояния и переходы. Откройте только компоненты и варианты, на которые ссылается этот экран.
2. Возьмите размеры, цвета и интервалы из YAML, когда он указан. Подключите общие компоненты по их контрактам. Воспроизведите состояние с теми же демонстрационными данными и размером окна, что на локальном кадре.
3. Выполните сценарий от входа до возврата. Сверьте результат с контрактом и кадром. Для применимых действий проверьте клавиатуру, фокус, сброс, пустую выдачу и прокрутку.
4. Реализуйте экраны и состояния из объявленного объёма. При недостающем правиле, данных или внешнем действии зафиксируйте экран, состояние и конкретный вопрос. Ссылки в поле `sources` YAML и материалы в `references/` нужны для сверки происхождения. Для обычной сборки достаточно контракта, параметров, контрольных данных и локального кадра.
