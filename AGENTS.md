# Работа со спецификациями Каталога данных

1. Выберите задачу в [обзоре](specs/Обзор.md). Прочитайте контракт порученной страницы и только обязательные зависимости.
2. Уточните доступные компоненты и правила интеграции в репозитории реализации. Поведение, состояние, данные и параметры берите у владельцев по ссылкам.
3. Повторно используйте общие компоненты. Параметры экземпляра, состояния и действия проверяйте в композиции страницы.
4. Для визуальной проверки воспроизведите указанные данные, состояние и размер окна. Для каждого затронутого пользовательского пути отдельно проверьте действие, результат, фокус и сохранение состояния, если они описаны.
5. Демонстрационные данные воспроизводят примеры. Серверные права, контракты API и внешние результаты определяются их владельцами. Границы поставки — в [README](README.md).
