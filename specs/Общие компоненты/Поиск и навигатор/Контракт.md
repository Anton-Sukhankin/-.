# Поиск и навигатор · контракт общего компонента

**Принято пользователем 5 ноября 2026.** Действующий контракт для воспроизведения принятой порции React-прототипа. [Состояния, действия и приёмка](<Состояния.md>) ведут поведение, [Вид](<Вид.md>) — композицию и параметры, [Источники вида](<Источники вида.md#кадры-принятой-реализации>) — локальные PNG и условия съёмки. Окружение подключает поиск в общем хедере.

## Граница и ответственность

Поиск C03 расположен в общем хедере. Он хранит запрос, выбранный тип, открытость выдачи и активную строку. Выдача показывает сгруппированные результаты, причину совпадения и доступные действия. Окружение открывает назначение по идентичности результата, раскрывает цель, управляет подсветкой и переключением совпадений на странице. Поле [B02 global-search32](<../Базовые элементы/Поле ввода/Контракт.md>) отвечает за ввод и размещение управляющих элементов. Состав и действия паспортов принадлежат соответствующим разделам.

В эту поставку входят пять типов ниже. Поиск находит записи, поля и индексируемые блоки по их содержимому. Служебные подписи кнопок, фильтров, вкладок и меню не индексируются.

## Поиск и данные выдачи

Демонстрационный поставщик выполняет поиск по подстроке после удаления крайних пробелов из запроса, без учёта регистра, с эквивалентностью «е» и «ё». Для объекта в глобальной выдаче берётся первое совпавшее поле в порядке таблицы. В каждой группе сначала точные совпадения названия, затем частичные совпадения названия, затем совпадения в остальных полях. При равном приоритете сохраняется порядок поставщика. Группы идут в порядке таблицы, пустые группы скрыты. Число в заголовке группы и число в футере считают результаты в выдаче с учётом выбранного типа. Это количество строк, отличное от счётчика вхождений на странице.

| Тип в выдаче | Где искать по порядку | Что показывает строка |
|---|---|---|
| Отчёты | Название, видимый вариант названия, домен, платформа, мастер-система | Название, домен, платформа и мастер-система из данных. Совпавший атрибут выделяется в строке метаданных |
| Источники | Техническое название, описание | Техническое название, платформа, домен. При совпадении в описании — фрагмент с подписью «Описание» |
| Поля источников | Название поля | Название, техническое имя родительского источника, SQL-тип. Одноимённые поля разных источников остаются отдельными результатами |
| Метрики и показатели | Название, заполненное описание в каталоге | Название, тип, домен, статус. При совпадении в описании — фрагмент «Описание». Для одноимённых объектов при совпадении названия — отличительный фрагмент описания или определения из данных |
| Блоки показателей | Текст блока, значения строк методики | Название показателя, название блока и фрагмент совпадения. У строки методики перед фрагментом показывается её подпись |

В выдаче совпавшие символы выделяются внутри названия, метаданных или фрагмента. На странице действует отдельный [вид метки](<Вид.md#вид-принятой-реализации>). Отсутствующие метаданные и описание не подменяются вымышленными значениями. Служебный текст «Описание не заполнено.» не участвует в поиске.

## Действия результата и назначения

Строка открывает **место совпадения**. Круглая кнопка справа открывает **паспорт того же объекта**, если паспорт доступен у результата. При совпадении в тексте переход открывает его контекст, включая вложенный блок. Если место для результата отсутствует, результат остаётся читаемым. Если назначение было доступно для выбора, но переход невозможен в текущем состоянии, выдача остаётся открыта и показывает «Место совпадения пока недоступно. Выберите другой результат.».

| Тип | Основное действие строки | Кнопка паспорта |
|---|---|---|
| Отчёт | Показать выбранный отчёт в каталоге. Для отчёта, представленного только в избранном, открыть «Главная → Отчёты → Избранное» | [Паспорт отчёта](<../../Разделы/Отчёты/Паспорт/Контракт.md>), вкладка «Обзор» |
| Источник | Показать источник в [каталоге источников](<../../Разделы/Источники/Контракт.md>), раскрыть совпавшее описание | Паспорт этого источника, вкладка [«Описание полей»](<../../Разделы/Источники/Детальная карточка/Описание полей.md>) |
| Поле источника | Открыть «Описание полей» именно родительского источника и выделить название поля | Отсутствует |
| Метрика или показатель | Показать объект в [каталоге метрик и показателей](<../../Разделы/Метрики и показатели/Контракт.md>) в выбранном виде | [Детальная карточка](<../../Разделы/Метрики и показатели/Детальная карточка/Контракт.md>) этого объекта, если доступна |
| Блок показателя | Открыть карточку родительского объекта, раскрыть нужный блок и выделить совпавший фрагмент | Отсутствует |

Для отчётов и источников с постраничным списком переход выводит нужную страницу. Если применённые фильтры исключают найденный отчёт, источник или метрику, каталог временно показывает только найденный объект с пояснением, сохраняя применённые фильтры. Для источника в таблице раскрывается полный текст найденного описания. Сохранение и сброс состояния, фокус и условия подсветки определены в [переходах](<Состояния.md#переходы-и-фокус>).

UI получает идентичность результата и принимающего объекта или блока, отображаемые поля, совпавший фрагмент и доступные назначения. Он передаёт намерение «показать место» или «открыть паспорт» с этой идентичностью. Прототип подставляет локальные демонстрационные данные. Производственные источники поиска, правила доступа, ранжирование за пределами описанного демо и хранение между сессиями остаются отдельными задачами интеграции.

### Общий набор отчётов для поиска · решение 3 ноября 2026

Для демонстрационного поиска доступны все 11 отчётов из объединённого набора. Каталоговый «План-Факт продажи» (`demo-report-sales-plan`) доступен для поиска и открытия по своему ID. Само присутствие в поиске не добавляет его в избранное. Состав и происхождение — в [демонстрационных данных отчётов](<../../../context/target/Демонстрационные данные отчётов.md>).
