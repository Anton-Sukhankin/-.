# Навигация · идентичность и визуальные источники

Адресная карта узлов, конфигурации и исходных изображений. Состояния пункта ведёт B11; композицию, активный section ID и сворачивание — родительский контракт. Текущая реализация без соответствующего Figma-эталона проверяется по зафиксированному локальному срезу, а source-изображения сохраняют свои даты и ограничения.

Связанный родитель: [Боковая навигация](<Контракт.md>). Правила соседних блоков подключаются по ссылкам; данные и состояние родителя не копируются.

Для раскрытого меню в обоих проверенных разделах выставлены `Controls?#2760:22=false`, `Checkbox?#2778:3=false`, `Status Dot?#2759:12=false`. Продуктовый список не должен получать checkbox, drag-ручки или контекстные инструменты из defaults исходного Tree.

Названия и счётчики пунктов используют **CoFo Sans Medium** независимо от состояния и выбранного раздела. Это правило распространяется на локальные мастеры и их рабочие экземпляры, включая скрытый счётчик, который может быть показан конфигурацией. Selected, Default и Hover различаются принятыми цветами и подложкой, а не начертанием. Удалённая библиотека не меняется; нужное начертание сохраняется в локальном семействе и конфигурации используемых экземпляров. Иконки, подписи и выбранный пункт зависят от раздела; имена и значения свойств не переводятся и не переименовываются этим контрактом.

### Локальный источник и границы «Задач»

Исходный общий стек — [локальный мастер1812:176559](https://www.figma.com/design/lnOcWh4ElGkhppWe6Kn5AA?node-id=1812-176559). Его экземпляры сохраняют выбранный раздел по идентичности, а не по порядковому индексу: добавление третьей строки не переносит Selected на соседний пункт. В той порции проверены92 раскрытых меню:43 Главная,42 Отчёты,5 Метрики и показатели,2 Источники. Для остальных разделов активных экранов в исходном наборе нет; их приёмка этим не заявляется.

Пункт «Задачи» подтверждён исходными демонстрациями и добавлен в макет по решению пользователя. Его внутренняя страница, доступность по ролям и внешние результаты не установлены; содержимое исключено из текущей работы. Число6 — fixture, не постоянный total. В исходном свёрнутом Figma-стеке сохранены neutral-кнопки; добавленная [кнопка1814:150725](https://www.figma.com/design/lnOcWh4ElGkhppWe6Kn5AA?node-id=1814-150725) стоит третьей,32×32,x15.5,y80. Последний пункт сдвинут до y296; шаг36 сохранён. Эти исходные размеры кнопки не отменяют текущую фиксированную сетку B11.

Иконка «Задач» — System / List из используемого набора, [источник1435:51163](https://www.figma.com/design/lnOcWh4ElGkhppWe6Kn5AA?node-id=1435-51163), тёмная#101D3B. SVG раскрытого пункта имеет20×20; SVG свёрнутой кнопки —16×16. Геометрия и цвета соседних разделов сохранены.
