# Список бесед AI-ассистента

Компонент левой колонки [панели](<Контракт.md>). В широком окне начальная ширина 240 px, минимум 160 px, максимум 360 px при наличии места для диалога. На промежуточных ширинах начальная ширина уменьшается вместе с доступной шириной панели. Строки имеют высоту от 36 px. Название занимает одну строку и обрезается многоточием при нехватке места. Переполненный список прокручивается внутри колонки.

| Действие | Видимый результат |
|---|---|
| «Новая беседа» | Создаётся новая пустая беседа, она становится активной. Черновики уже начатых бесед остаются доступны. |
| Выбор беседы | Показаны сообщения, режим и черновик выбранной записи. Фокус переходит в композер. |
| «Свернуть список чатов» | Колонка сжимается до 64 px, «Новая беседа» и беседы остаются круглыми кнопками с доступными названиями. Вместо заголовка «Чаты» виден разделитель. |
| Изменение ширины | Правая граница подсвечивается при наведении и перетаскивании. Ширина меняется указателем или клавиатурой в пределах доступного места. |
| Меню строки | Троеточие видно при наведении, клавиатурном фокусе или открытом меню. Пункты «Переименовать» и «Удалить». |
| Переименование | По пункту меню или двойному клику поле открывается на месте. Двойной клик в свёрнутом списке сначала раскрывает колонку. Подтверждение сохраняет непустое название, отмена возвращает исходное. |
| Удаление | Открывается центрированное модальное подтверждение с затемнением. Отмена сохраняет беседу и возвращает фокус в действие строки. Подтверждение удаляет выбранную запись. При удалении активной беседы выбирается оставшаяся, а при пустом списке открывается пустой диалог. Фокус переходит к композеру. |

Данные строки — устойчивый идентификатор, название и признак активной беседы. Название новой записи до первой отправки — «Новая беседа». После первого сообщения оно берётся из вопроса, если пользователь уже не задал другое название. Количество и названия бесед изменяются с данными сеанса.
