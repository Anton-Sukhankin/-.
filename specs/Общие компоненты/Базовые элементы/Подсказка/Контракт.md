# Подсказка краткого определения

П4-13 · B16. Документальная декомпозиция4ноября2026. Единственный владелец представления и подтверждённой механики **подсказки определения** на info-иконке. Точные параметры — [Параметры.yaml](<Параметры.yaml>), их формат — [общий ресурс](<../../../Ресурсы/Параметры компонентов/README.md>). Данные определения и выбранного объекта остаются у [раздела метрик и показателей](<../../../Разделы/Метрики и показатели/Контракт.md>), продуктовый смысл — у [решения28октября](<../../../../context/target/Требования/Карточки.md#полная-карточка-показателя--определение-в-подсказке-решение-28-октября>). Этот перенос не является новой приёмкой runtime.

## Два назначения и владельцы

| Назначение | Владелец и применение | Условие показа |
|---|---|---|
| Краткое определение по info-иконке | B16 metric-definition16; подтверждённое применение — шапка полного паспорта метрики/показателя | Наведение или фокус на отдельном триггере; не зависит от того, обрезано ли название |
| Полный исходный текст обрезанного значения | [Контракт текстовых подсказок](<../../Текстовые подсказки/Контракт.md>), OverflowText | Только при фактической обрезке текста. Поверхность оформления общая с B16. |

OverflowText определяет условие показа полного текста. B16 ведёт механику отдельной info-иконки и визуальные параметры поверхности. Служебные пояснения иконок и недоступных действий остаются у владельцев действий.

## Устройство и применение

В компонент входят отдельная info-кнопка с декоративным glyph и появляющийся текстовый popup. Слот триггера, корпус popup, типографика и параметры соединяющей hover-области разрешаются из metric-definition16 в YAML. Glyph — отдельный [SVG](<../../../../assets/images/metrics/detail/info.svg>), его собственные размеры13.3334/viewBox сохранены; наблюдаемый CSS рисует его13.3333 внутри слота. Размер glyph не заменяет размер кнопки. Цвет/рисунок остаются в SVG, не повторяются вторым набором paint-параметров.

Паспорт размещает триггер рядом с названием по своему heading/gap; отступ после названия и внешняя шапка не становятся внутренним padding B16. Текущий родитель передаёт text=metric.description и key=metric.id: определение принадлежит выбранному объекту. Новый ID пересоздаёт локальное состояние подсказки закрытым. Полное описание, условия, исключения и формула остаются в содержимом паспорта. Образец исходного ID4 проверяется по его источнику; текст не записывается константой в общий YAML и не подставляется другим объектам.

Подтверждённый popup содержит только текст, без заголовка, ссылок, кнопок и управления фокусом внутри. Нет неподтверждённого правила для отсутствующего определения: его нельзя заменять чужим текстом, формулой или общим «Информация». Источник краткого определения требуется на границе данных выбранного объекта; получение/серверное хранение не принадлежат B16.

## Состояния и переходы

Видимые состояния YAML — closed/open. Закрытие Escape дополнительно сохраняет наблюдаемый флаг подавления повторного hover; это guard той же закрытой формы, не новый визуальный вариант.

| Исходное условие и событие | Видимый результат | Подтверждённая граница |
|---|---|---|
| Новый экземпляр | Popup закрыт | Локальный visible=false; родитель key выбранного ID не заменяется глобальным кешем |
| Pointer входит в корень и Escape-guard не установлен | Popup открыт с переданным text | Не требуется clipping названия; отдельной фиксированной задержки нет в текущем коде |
| Кнопка получает фокус | Guard сбрасывается, popup открывается | Стандартный Tab-фокус; фокус не переносится на текст подсказки |
| Pointer переходит с кнопки на popup через соединяющую область | Открытая подсказка сохраняется | Текст и bridge входят в корень; после hover текст можно прочитать, не удерживая pointer над glyph |
| Pointer покидает корень | Сбрасывается hover/guard; popup закрывается, если фокус не находится внутри корня | Открытая подсказка при сохранённом фокусе не закрывается только от ухода pointer |
| Фокус уходит за пределы корня | Guard сбрасывается; popup закрывается, если pointer уже вне корня | При наведении на корень открытый popup сохраняется |
| При открытом popup нажата Escape | Popup закрыт, устанавливается guard повторного hover | Оставшийся над кнопкой pointer не открывает его немедленно. Следующий выход/вход pointer либо новое получение фокуса восстанавливают обычное открытие |
| Экземпляр размонтирован или закрыт | Обработчик Escape снят | Текущий effect подписывается только при visible; новый выбранный объект не наследует старую открытую форму |

Нативная кнопка имеет доступное имя «Определение показателя». При open она связана через aria-describedby с уникальным id текстового role=tooltip; при closed эта связь отсутствует. Glyph декоративен, alt="". У popup нет собственной Tab-остановки. Текущий код не задаёт переключение по клику/Enter/Space, закрытие по outside-click, таймер, автопоказ, повторное открытие сразу после Escape или особую Arrow/Home/End-навигацию — эти действия не добавляются по аналогии с меню/вкладками.

## Пространство и слои

Корень info относителен, popup позиционирован абсолютно относительно него и перекрывает содержимое без изменения layout. Параметры popup и bridge находятся в YAML; высота popup определяется текстом и не фиксируется высотой одного снимка. Наблюдаемый z-index — локальное значение, не гарантия поверх любого портала системы. Родитель сохраняет собственный слой шапки и ограничения композиции.

Соединяющий псевдоэлемент заполняет промежуток до popup и использует его ширину; это поддержка перехода pointer, а не видимый дополнительный фон. Открытие не растягивает заголовок, не сдвигает атрибуты или аккордеоны. В текущем коде нет viewport-flip/auto-shift/портала или отдельной узкой композиции popup; способность автоматически избегать всех краёв окна не заявляется. Неустановленные мобильные, touch и отсутствующее определение остаются ограничениями зависимого применения.

## Проверка и ограничения

1. Из паспорта находятся B16, metric-definition16, оба исходных состояния, текст выбранного объекта и SVG; маршрут OverflowText остаётся отдельным.
2. Проверяются параметры по MP05.1a/текущему CSS, источник каждого значения, точность glyph и сохранность Figma URL. Нет фиксации высоты по одному примеру.
3. По таблице переходов различаются hover, focus, удержание pointer/focus, Escape-guard и новый объект. Это документальная сверка существующих обработчиков, не утверждение нового выполненного браузерного сценария.
4. Проверяются схема YAML, локальные ссылки/якоря, сохранность файлов и смысл данных. Вся автономная упаковка и относительные зависимости вне проекта проверяются на П7.

Первоначальная документальная декомпозиция B16 не меняла приложение. По последующему решению пользователя подсказки полного текста используют общую поверхность B16, а их условия показа ведутся отдельным контрактом.
