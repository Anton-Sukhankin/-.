# Счётчик

Владелец B12: оформление переданного числового значения в подтверждённом контексте. [Параметры.yaml](<Параметры.yaml>) — единственный владелец внутренних параметров перечисленных вариантов. Это декомпозиция существующих описаний и наблюдений; продукт, приложение и Figma не меняются. [Формат параметров](<../../../Ресурсы/Параметры компонентов/README.md>) общий с другими базовыми элементами.

## Граница и маршрут

Применение → нужный вариант B12 → его источник/эталон. Название «счётчик» не устанавливает одинаковые оформление, бизнес-смысл или способ вычисления числа.

| Факт | Владелец |
|---|---|
| Текст/подложка/контур/типографика и подтверждённые состояния конкретного варианта | B12 |
| Значение, его смысл, форматирование, условие показа и отсутствие данных | Потребитель |
| Selected родительской вкладки/сегмента и положение счётчика рядом с подписью | [B10](<../Вкладки/Контракт.md>) / [B09](<../Сегмент-контрол/Контракт.md>) |
| Скрытие текста при сворачивании, текущий раздел и состав пунктов | [B11](<../Пункт навигации/Контракт.md>) / C01 |
| DRAFT/APPLIED, число заполненных атрибутов, общий Reset/Apply и его результат | [C05](<../../Фильтрация отчётов/Контракт.md>) / FL |
| Размещение trailing count относительно action и кнопки раскрытия | [C09](<../../Аккордеон/Контракт.md>) |

Счётчик получает уже подготовленное значение и вариант. Он не выполняет подсчёт сущностей/условий, не загружает totals и не хранит второй набор выбранных значений. Сокращение до99+, округление, локализация и максимальное допустимое число не определяются размерами исходника. Необязательное значение не заменяется нулём автоматически.

## Варианты

| Вариант YAML | Подтверждённый контекст | Ограничение |
|---|---|---|
| navigation-text14 | Текст справа от подписи раскрытого пункта C01/B11, без pill | Цвет счётчика не становится цветом selected-подписи; в свёрнутом режиме скрывает родитель |
| tab-count16 | Вкладки/сегменты Главной и текущие табы паспорта | Selected приходит от B10/B09; max-width текущего CSS не является правилом99+ |
| filter-header16 | Синий headline панели фильтрации | Не кнопка сброса, значение относится к DRAFT |
| filter-reset16 | Наложенный индикатор общей кнопки фильтров | Значение относится к APPLIED; hover показывает отдельный glyph сброса, действие принадлежит C05 |
| accordion-count16 | Числовой count общего Accordion | Строковый count — отдельная muted-подпись C09, не этот badge |
| search-count16 | Серая метка заголовка группы глобального поиска | Цвета/радиус/line-height отличаются от tab-count16; не footer-total |
| domain-count16 | Метка группы карточек/таблицы отчётов; тот же count-класс у групп словаря | В отчётах относится к показанному набору домена; в словаре передаются исходные totals группы. Смысл и число определяет потребитель |

Основной текст использует CoFo Sans. Font-weight задаётся только там, где он подтверждён; у accordion-count16 он наследуется из места применения и не объявляется новым Medium-правилом. Размеры и цвета вариантов не усредняются. Различие между строкой навигации и компактной меткой сохраняется.

У tab-count16 и filter-reset16 существующий CSS ограничивает ширину, но не вводит бизнес-лимит числа. Поведение длинных значений визуально полностью не проверено; исходное значение не усекается по выдуманному правилу. Остальные показанные компактные варианты имеют минимум ширины и могут расширяться по содержимому. Прочие badge и числовые подписи системы не назначаются этому набору по одному имени класса.

## Состояния и данные применения

| Контекст / условие | Отображение и ответственность |
|---|---|
| Навигация: count отсутствует | Метки нет; это не число0. Переданный0 не подменяется отсутствием |
| B10/B09: count задан, включая0 | Показать переданное значение; цвет следует selected родителя, но не изменяет его выбранность |
| Панель: draftAttributeCount>0 | Показать filter-header16. По FL считается число заполненных атрибутов, не число значений внутри одного атрибута |
| Общая кнопка фильтров: applied count>0 | Показать filter-reset16; при0 индикатор отсутствует. Смена DRAFT сама не меняет APPLIED-индикацию |
| Hover filter-reset16 | Скрыть цифры визуально и показать reset-hover.svg; фон становится нейтральным. Доступное имя кнопки продолжает описывать сброс и количество атрибутов |
| Активация filter-reset16 | Вызвать переданный родителем обработчик сброса. B12 не вычисляет результат, не выполняет Apply и не закрывает панель самостоятельно |
| Accordion: number count задан, включая0 | Числовой badge; с action он переносится в trailing-область, без action находится в заголовке. Это размещение C09, не второй независимый count |
| Accordion: string count, в том числе "0" | Muted-текст C09; числовая форма и стили B12 не назначаются преобразованием строки |
| Поиск / доменная группа | Показывать значение, которое передал текущий набор/группа. Появление самой группы и смысл количества определяет потребитель |

Статическая метка не получает собственную кнопку, Tab-остановку, aria-live или намерение выбора. Внутри вкладки/сегмента она не становится вложенной интерактивной кнопкой. У filter-reset16 самостоятельная native button type=button — подтверждённое исключение: обычная активация и доступное имя принадлежат переданному действию, а не всему семейству счётчиков. Положение overlay, слот glyph и привязка к кнопке фильтров остаются у FilterButton/C05; outline текущего CSS не превращается в дополнительную высоту тела badge.

Счётчик DOM-текста не является отдельным изображением. Рисованные курсоры, состояния disabled/loading и автоматические tooltip из DS не добавляются без подтверждённого применения. Точные числа примеров128/10/1 и разные totals исходных кадров не являются константами компонента.

В accordion CSS поздняя декларация `.count` переопределяет прежние padding1×4 на0×3 и line-height16; переносится эффективное значение, а не первая найденная строка. Дополнительные max-width/tracking, разные background/line-height, focus/reset-рисунок и доменные метки сохраняют статус наблюдений реализации. Сходство формы не повышает их до новой пользовательской визуальной приёмки.

У filter-reset16 [точный glyph14×14](<../../../../assets/images/filter-trigger/reset-hover.svg>) показывается вместо цифр, без растрового вырезания. Его доступное имя задаёт кнопка; сам SVG декоративен. Ресурсы/манифесты C01/C03/Главной/паспорта остаются на прежних местах; [шрифты](<../../../Ресурсы/Шрифты/README.md>) общие.

DS [v-counter5667:17429](<../../../../references/design-system/docs/design-system/components/generated/DS-01-5667-17429.md>) и [v-counter-button2925:13071](<../../../../references/design-system/docs/design-system/components/generated/DS-01-2925-13071.md>) — разные исходные семейства. Их полный набор вариантов, размер24, max26 и пример+2 не становятся правилами проекта. Источники читаются без изменений; live-актуальность, новый runtime и новые визуальные эталоны этой порцией не подтверждаются.

## Документальная приёмка

Сверить параметры каждого варианта с прежними владельцами и эффективным CSS, ссылки B11 на четыре перенесённых значения и B09/B10 на нового владельца. Проверить отсутствие/0, number/string Accordion, selected родителя, DRAFT/APPLIED и исключение reset-control. Сохранить Figma URL, ресурсы, схему и адресные маршруты; не приписывать общей метке вычисление чисел или готовность неизвестных длинных значений.
