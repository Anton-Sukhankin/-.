# Селект B04

Владелец поля и управления выбором B04. Собственная поверхность строки — [B05](<../Строка списка/Контракт.md>); семейство параметров B04/B05 остаётся единым. Выделен из действующей фильтрации без изменения принятых продуктовых правил. [Точные параметры](<Параметры.yaml>) — единственный редактируемый источник численных стилей этого семейства; [схема и проверка](<../../../Ресурсы/Параметры компонентов/README.md>) относятся к данным документации, не реализации приложения.

## Граница и ответственность

Компонент включает подпись и поле-триггер, индикатор раскрытия, поверхность значений, необязательное поле поиска, прокручиваемую область и повторяемую строку выбора. Список может использоваться отдельно внутри меню колонки без собственного поля/тени. Типографика и интервалы селекта принадлежат этому контракту и YAML; внутреннее поисковое поле подключается из B02, а внешнее размещение полей, набор значений и бизнес-смысл выбора — у потребителя.

Компонент получает доступные значения с устойчивой идентичностью и отображаемой подписью, текущее выбранное значение/множество, режим выбора, вариант размеров, наличие поиска и состояние открытости. Он показывает выбор и передаёт намерение изменить его. Источник справочника, внешняя фильтрация, DRAFT/APPLIED, действие Apply, общий сброс и контекст набора не становятся ответственностью базового селекта.

## Варианты и состав

Идентификаторы вариантов — ключи `variants` в YAML. Общие параметры `base` действуют с учётом наличия соответствующей части; параметры отсутствующего поля не заставляют рисовать поле у встроенного списка.

| Вариант | Состав / настройка применения | Что он не определяет |
|---|---|---|
| panel-wide | Поле и собственный popup; широкое применение общей панели, обычная левая привязка | Не определяет справочник и момент применения |
| panel-narrow | Поле и popup узкого применения | Не превращает всякое узкое поле в одиночный выбор |
| panel-owner | Узкое поле и расширенный popup с правой привязкой | Значения владельцев и множественный выбор передаёт родитель |
| panel-status | Узкое поле; одиночные текстовые строки, визуально скрытые radio | Значения/смысл «Все» и момент применения принадлежат родителю |
| embedded-list | Только поиск при его наличии и строки внутри чужого меню | Не добавляет поле, внешнюю сортировку, shadow или собственные Reset/Apply |
| single-choice-popup | Самостоятельный одиночный селект с combobox/listbox/option и одной галочкой; описание ниже, точные параметры — одноимённый вариант YAML | Не наследует DRAFT/Apply отчётной панели, её panel-* геометрию и наборы |

Обычные дискретные фильтры отчётов используют множественный выбор; статус — одиночный. По уточнению пользователя4ноября поиск в multiple-списке скрывается, если полное число вариантов меньше семи. При семи и более сохраняется настройка поиска фактического контекста; одиночный режим сохраняет прежнюю настройку. Компактный доменный источник без поиска и список с поиском — разные конфигурации, не разные справочники по умолчанию. MAU и последний просмотр являются диапазонами и не относятся к этому семейству.

## Поле и оформление

Размеры и цвета читаются по ключам `field-*`, `label-*`, `value-*`, `glyph-*`, `surface-*`, `option-*`, `search-*` в YAML. Внутренние параметры поискового input теперь читаются из [B02](<../Поле ввода/Параметры.yaml>) через типизированные ссылки с точными locator; второй числовой копии здесь нет. Применяется list-search32, не global-search32. search-region-height/search-padding описывают внешний контейнер, поэтому остаются у B04; поиск и строка выбора не объединяют свои состояния с глобальной выдачей. Семейство шрифта подключено к [каноническому ресурсу шрифтов](<../../../Ресурсы/Шрифты/README.md>); он определяет наличие файлов, а не подтверждает загрузку в приложении.

Рамка рисуется внутри габарита поля. Горизонтальные внутренние отступы и правый отступ glyph измеряются от внешней границы: толщина рамки не прибавляется к требуемому расстоянию. Значение занимает оставшуюся ширину с предусмотренным промежутком перед glyph; отдельная фиксированная ширина строки текста не вводится. Историческое измерение текстовой области исходного wrapper сохранено у источника, но не является дополнительным независимым ограничением ширины текста.

Индикатор закрытого поля направлен вниз; открытого — вверх. Поворот отражает открытость, а не наличие выбранных значений. [Существующий SVG поля](<../../../../assets/images/filter-panel/chevron-domain-status.svg>) доступен как ресурс текущей демонстрации, root16×16; это не подтверждение опубликованного DS-binding для всех вариантов. Полноту иных glyph и библиотечное сопоставление проверяют отдельно.

Наблюдаемый исходный padding71 при фиксированном поле не применяется как вертикальный отступ. Высота блока равна сумме высоты подписи, её промежутка и поля из YAML. Графика и текст вертикально центрируются по видимым габаритам.

## Теги множественного выбора · решение 4 ноября 2026

По прямому поручению пользователя правило действует во всех полях прототипа с режимом multiple, включая технический просмотр. В закрытом и открытом поле выбранные значения и счётчик оформляются тёмно-серыми тегами с белым текстом. Крестик удаления тега наследует цвет текста. Численные параметры оформления ведутся в [Параметры.yaml](<Параметры.yaml>) под ключами multi-tag-*, multi-counter-*, multi-selected-* и multi-remove-*.

Порядок тегов соответствует порядку выбранного множества. Если все названия помещаются, счётчика нет. Если следующий тег не помещается, показывается «+N», где N — число скрытых выбранных значений. При нехватке места для счётчика предыдущий видимый тег сокращается по ширине, его текст получает многоточие; счётчик остаётся доступным. Полное имя сокращённого тега доступно при наведении на текст. Для одного длинного значения сокращается его тег, без выдуманного счётчика. Расчёт повторяется при выборе, удалении, изменении ширины и загрузке шрифта.

Следующее уточнение пользователя4ноября: у каждого видимого тега постоянно есть собственный крестик, удаляющий только его значение. При наличии хотя бы одного выбранного значения рядом со стрелкой поля есть отдельный крестик очистки всего выбора этого поля, включая скрытые значения. Очистка не сбрасывает соседние поля и не выполняет Apply. После удаления последнего значения обе индикации исчезают; поле возвращается к пустому представлению. Удаление и очистка при раскрытом основном списке сохраняют его раскрытие и синхронно снимают соответствующие checkbox. Кнопки удаления и очистки не вложены в основную button; для них резервируется место при упаковке, текст сокращается без перекрытия крестиков/счётчика/стрелки. Фокус после удаления остаётся у следующего видимого удаления либо основной кнопки; после очистки — у основной кнопки.

Порог поиска определяется по всему доступному списку **до** текстового поиска, не по количеству выбранных значений и не по оставшимся результатам. Поэтому ввод запроса, оставившего одну/ноль позиций в исходном длинном списке, не прячет search и не лишает возможности исправить запрос. FilterValueList получает обязательный totalOptionsCount; то же правило используют расчёты высоты/позиции списков общей панели, меню колонок и технических просмотров. При скрытом поиске его область и занимаемая высота убираются полностью. Численный порог и размеры крестиков — в multi-search-*/multi-clear-*/multi-tag-remove-* YAML.

При наведении на счётчик **в свёрнутом поле** открывается отдельный список из ровно N скрытых выбранных значений в порядке выбора. Видимые теги, включая сокращённый тег с многоточием, в список не входят. Основной список вариантов остаётся закрытым. Имена показываются полностью с переносом, длинный список прокручивается. При наведении на строку справа появляется круглая кнопка с крестиком. С клавиатуры удаление видно при фокусе, на устройстве без hover — постоянно. Удаление меняет текущее множество у владельца поля. Теги, счётчик и список пересчитываются сразу. Если после удаления скрытых значений нет, счётчик и список исчезают, фокус возвращается на поле.

Счётчик также открывается фокусом/нажатием; ArrowDown переводит фокус к удалению. Escape закрывает только dropdown выбранных значений и возвращает фокус к счётчику, оставляя панель. Наведение не перехватывает фокус. Задержка закрытия позволяет перевести курсор через зазор в dropdown; выход закрывает список, если фокус не внутри. Клик вне списка закрывает его. Раскрытие основного селекта закрывает просмотр выбранных значений.

Компонент получает реальные пары value/label, не разделяет строку по запятым. ID удаления относится к значению; одинаковые подписи не заменяют идентичность. Поле и счётчик — соседние кнопки одного визуального поля, без вложения button в button. Основная кнопка сохраняет доступное имя со всеми значениями; счётчик имеет собственные aria-expanded/aria-controls.

Реализация — [MultiSelectTrigger](<../../../../references/implementation/components/MultiSelectTrigger/MultiSelectTrigger.tsx>) и [размещение тегов](<../../../../references/implementation/components/MultiSelectTrigger/packTags.ts>). Потребители — Отчёты, Избранное, Источники и стенд панели. В отчётах и источниках удаление меняет черновик до «Применить». Браузерные проверки скрытых значений и фокуса, снимки предыдущей версии.

[Кадр 5 ноября, Chromium, 1440×900](<Изображения/hidden-tags-2026-11-05.png>). В каталоге Отчётов открыть панель фильтров, выбрать первые три значения поля «Владелец», свернуть список поля и навести на «+2». Один сокращённый тег виден в поле, две скрытые записи показаны в отдельном списке.

## Самостоятельный селект одиночного выбора

Компонент [SingleSelect](<../../../../references/implementation/components/SingleSelect/SingleSelect.tsx>) построен на уже установленном Radix Select. Он заменяет нативные select в каталоге метрик, связанных метриках отчёта, стендах переключателей Главной, меню фильтров и обоих стендах новостей. У всех одно оформление popup и исходная галочка. Ширину/расположение поля и смысл выбора задаёт потребитель. Существующие вкладки, сегмент-контролы, независимые флаги и поисковые результаты-переходы не становятся селектами.

Поле открывается мышью, Enter/Space или стрелками; список получает доступное имя поля. Стрелки/Home/End и ввод по первым буквам перемещают фокус. Enter/Space либо нажатие пункта фиксируют значение и закрывают popup; Escape закрывает без фиксации сфокусированного нового варианта, фокус возвращается к полю. Popup учитывает границы окна, длинные списки прокручиваются без появляющихся кнопок, сдвигающих пункты под курсором. Фокус клавиатуры имеет синюю рамку; наведение мыши — только светлую подложку. У недоступных пунктов выбор заблокирован.

«Все» в самостоятельном селекте — реальная опция снятия ограничения, также отмечаемая одной галочкой. Внутреннее техническое кодирование пустого значения не передаётся потребителям. Повторный выбор не снимает одиночный выбор. Семантика single-choice FilterValueList остаётся native radio под общей визуальной строкой; в сортировке сохранены кнопки с aria-pressed и одна галочка у направления. Пока сортировка отсутствует, ни одно направление не отмечено; исходный порядок не подменяется автоматическим выбором А→Я.

Момент применения не унифицируется визуальным компонентом: метрики фильтруются сразу, отчётные и source-фильтры показывают выбор черновика до общего/локального «Применить». Смена вида, история и возврат сохраняют состояние у соответствующего владельца. Поиск с результатами-переходами не показывает галочку как будто это поле с сохранённым выбором.

Переход от «Все» к статусу и обратно передаётся родителю как выбранное значение, а не как готовый серверный фильтр. Замену единственного значения, сохранение его при повторном выборе и подтверждённую native-клавиатуру ведёт [B06](<../Контрол выбора/Контракт.md#действия-и-состояние>). Это не объединяет общую/локальную транзакции или статусы других каталогов; полный клавиатурный контракт остальных полей не восстановлен по одному рисунку.

## Открытие, поиск и прокрутка

| Условие / действие | Видимый результат и граница |
|---|---|
| Родитель/пользователь открывает поле | Видна поверхность его значений, glyph отражает открытость; источник значений не заменяется |
| Выбор значения | Обновляется переданный локальный выбор и сообщается намерение родителю; общей выдачи компонент самостоятельно не меняет |
| Введён запрос поиска | Остаются подписи с подстрокой без учёта регистра; это поиск значений одного атрибута, не глобальный поиск отчётов |
| Набор больше максимума из YAML | Полный набор сохраняется под clipping, видны только полные строки и полоса вертикальной прокрутки; последняя позиция достижима |
| Набор короче максимума | Естественная высота `N × option-height + (N−1) × option-gap`, без резерва до максимума и без полосы |
| Есть строка «Все» | Она учитывается в числе видимых строк; скрытые шаблонные элементы не становятся данными |
| Прокручиваются варианты | Поиск, внешняя сортировка и footer не прокручиваются вместе с ними |
| Закрытие / Escape / внешний клик | Передаётся или исполняется установленное родителем правило; отмена/сохранение черновика не угадываются внутри селекта |

Максимум выводится из `max-visible-options`; высота viewport — произведение высоты строк и промежутков, нижний padding поверхности находится снаружи. Для нулевого результата источник не устанавливает универсальную новую иллюстрацию или текст: согласовать применение, не копировать NoResults глобального поиска. Схема параметров не объявляет обязательными loading/error/disabled или новые варианты ради заполнения шаблона.

В общей панели закрытие всей панели отменяет неприменённый DRAFT по FL-01, даже если открыт дочерний список. В локальном меню колонки закрытие отменяет локальный DRAFT по FL-02. Эти две транзакции не заменяются соглашением старого изолированного стенда «Escape закрывает только dropdown и сохраняет черновик».

## Привязка поверхности

Для вариантов panel-* обычный popup совпадает по ширине с полем и открывается с зазором из YAML вниз; при нехватке места снизу — вверх от того же поля. Вариант panel-owner задаёт расширенную ширину и правую привязку; расширение уходит влево. При прокрутке и resize привязка пересчитывается. Рамка остаётся в viewport; тень не входит в измерение зазора. Если окно уже поверхности или места недостаточно с обеих сторон, новое сжатие/уменьшение количества строк этим контрактом не утверждается.

У embedded-list нет самостоятельной привязки к заголовку: внешняя поверхность принадлежит [контексту меню колонки](<../../Фильтрация отчётов/Меню колонки.md#композиция-и-размещение>). Сдвиг такого меню влево не создаёт vertical flip или авто-закрытие при scroll. Ошибочный y420 старого доменного PNG не является правилом позиционирования ни одного варианта.

## Приёмка и ограничения

Проверять YAML по схеме и соответствие выбранного варианта источнику; отдельно сверить наблюдаемые размеры рамки/отступов, glyph и viewport строк. Для многозначного списка проверить несколько ID, поиск и последнюю строку; для статуса — замену единственного значения и отсутствие видимого radio; для owner — правую привязку при разных окнах. Сценарии Apply/Reset/Close проверяются у каждого родителя по FL-01/FL-02.

У автономного каталога метрик селекторы типа/статуса применяются сразу по [их владельцу](<../../../Разделы/Метрики и показатели/Контракт.md#фильтры-каталога>). Их точное визуальное соответствие panel-* не установлено; нельзя присвоить им данный вариант только по слову «селектор». Права, API, серверные справочники, межсессионное хранение, полный набор ошибок/загрузки и пригодность живых Figma-ссылок эта порция не определяет. Приёмка документации не означает проверки runtime или pixel-perfect всех состояний.
