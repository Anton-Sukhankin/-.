# Чипс выбора

B08 описывает оформление и активацию одного чипса. Числовые параметры вариантов ведёт [YAML](<Параметры.yaml>). Состав группы, выбор по умолчанию и результат действия задаёт экран.

## Граница и чтение

Маршрут: конкретное применение → этот контракт и нужный вариант YAML → соответствующий эталон/ресурс. Для изменения одного чипса не требуется читать все состояния поиска или всю панель фильтрации.

| Факт | Владелец |
|---|---|
| Корпус, внутренние отступы, типографика, enabled/active и отдельно подтверждённые дополнительные стили одного чипса | B08, этот контракт/YAML |
| Подписи, идентичность и порядок типов, набор выбранных типов и группы выдачи | [C03: состояния поиска](<../../Поиск и навигатор/Контракт.md#поиск-и-данные-выдачи>) |
| Высота/отступы зоны типов, расстояние между чипсами и кнопка сброса | [C03: вид поиска](<../../Поиск и навигатор/Вид.md>) |
| Ряд пресетов, его расстояние от поля и между элементами, отображение только у MAU, преобразование активации в диапазон и вычисление active | [B07: шкала и пресеты](<../Диапазон/Контракт.md#шкала-и-пресеты>) |
| Пороговые значения/подписи, текущий DRAFT, момент Apply/Reset, влияние на результат | [C05: применение диапазонов](<../../Фильтрация отчётов/Контракт.md#настройки-числовых-атрибутов>) и FL |

Чипс получает вариант, подпись, идентичность и признак выбранности от потребителя. Активация сообщает потребителю, какой элемент нажат; это смысл UI-намерения, не новый API или обязательные имена props. Родитель обновляет своё состояние и возвращает выбранность. У чипса нет второго независимого набора выбранных значений.

## Варианты и применение

| Вариант | Подтверждённое применение | Ограничение |
|---|---|---|
| search-type32 | Текстовый чипс шириной по подписи. Навигатор, AI Hub, «Мои вопросы», переключатели условий CRM | Число одновременно выбранных значений и последствия выбора задаёт экран |
| mau-preset28 | Кнопка нижнего порога MAU под числовым полем; ширина по подписи | Активность вычисляет B07 из диапазона; это не общий режим toggle и не дополнительное ограничение поверх имеющихся краёв |
| mailing-channel42, mailing-weekday42 | [Расписание рассылки](<../../../Разделы/Отчёты/Паспорт/Рассылки.md#создать-рассылку>). Канал занимает ширину подписи, день недели имеет минимальную ширину по YAML | Нажатие переключает одно значение в своей группе. Форма задаёт начальный выбор и хранит черновик |

Поиск и MAU используют CoFo Sans Medium, расписание — Regular. Внешние отступы и перенос групп задаёт экран.

Подтверждённые текстовые варианты не наследуют Close, info, счётчик или tooltip из макета. Счётчик появляется только в применениях, где он явно описан. Удаление выбранного значения крестиком не установлено. Общие теги B13 и сегмент-контрол B09 не заменяют B08 по сходству названия. В частности, источник XS segment item для MAU не доказывает принадлежность всех segment items этому семейству.

В Навигаторе каждый раздел отображается собственным чипсом в общем ряду. Порядок, перенос и счётчики определяет [Навигатор](<../../Поиск и навигатор/Вид.md#применение-текстовых-чипсов>).

## Активация и состояния

| Условие / событие | Реакция и граница |
|---|---|
| enabled, выбранность false | Показать нейтральное оформление своего варианта |
| Потребитель передал выбранность true | Показать active своего варианта; источник этого признака остаётся у потребителя |
| Активация search-type32 в Навигаторе | Переключает один раздел в текущем наборе. [Навигатор](<../../Поиск и навигатор/Состояния.md#поле-и-выдача>) ведёт выбранные разделы, сброс и выдачу |
| Активация чипса расписания | Переключает выбранность этого чипса. Остальные сохраняют состояние. Выбранный чипс получает голубую подложку, синюю рамку и синий текст |
| Активация mau-preset28, в том числе уже активного | Передать активацию пресета B07. B07 заменяет всю пару на соответствующий нижний край без верхнего; повтор сохраняет диапазон, а не снимает выбор |
| MAU изменён вручную или сброшен | B07 заново вычисляет active: точное равенство нижнего края порогу и отсутствие верхнего; произвольный диапазон может не выделять ни одного пресета |
| Нажат пресет без Apply | Изменяется относящийся DRAFT у прежнего владельца. Чипс сам не применяет фильтрацию, не закрывает меню и не сохраняет APPLIED |

Текстовый чипс доступен по Tab. Enter и Space выполняют то же действие, что клик. Доступная выбранность отражается через aria-pressed. Контур клавиатурного фокуса может отображаться поверх выбранного состояния.

Enabled и active поиска перенесены из среза Figma C03. Текущий CSS поиска резервирует прозрачную рамку в enabled, сохраняя общий размер, тогда как исходный enabled описан без видимого stroke; это не новая видимая обводка. Дополнительный focus поиска, hover/focus/transition MAU и отключение перехода при reduced motion отмечены в YAML как observed-snapshot. У выбранного пресета белый active-фон сохраняется и при hover по порядку существующего CSS; focus добавляет контур, не сбрасывая выбранность. Непоказанные disabled/loading/error, search hover и activated-hover из общей DS автоматически не включаются.

## Документальная приёмка

Проверить точность обоих вариантов по прежним владельцам и CSS, отсутствие второго владельца их числовых стилей, неизменность подписей/данных/смыслов применения, сохранность Figma URL/изображений/шрифтов и маршруты C03→B08 и C05→B07→B08. Отдельно различить повтор MAU и неизвестные сочетания типов; сброс типов, query и общий Reset остаются у своих владельцев. Эта приёмка не подтверждает новую визуальную реализацию, внешний поиск или backend-фильтрацию.
