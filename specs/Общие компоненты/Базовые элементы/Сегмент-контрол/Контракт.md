# Сегмент-контрол

Владелец B09: группа взаимоисключающего выбора, её внутреннее оформление и активация. Точные параметры вариантов text40, icon40, icon-tree40 и mailings-mode — в [Параметры.yaml](<Параметры.yaml>), формат — [общий для базовых элементов](<../../../Ресурсы/Параметры компонентов/README.md>).

## Граница и маршрут

Применение страницы → этот контракт и нужный вариант YAML → соответствующий ресурс/эталон. Разработчик переиспользует компонент, а данные, действие выбранного пункта и внешнее размещение задаёт конкретное применение.

| Факт | Владелец |
|---|---|
| Контейнер, элементы, внутренние отступы, выбранное/невыбранное оформление, активация выбора | B09 |
| Список ID/подписей, необязательные counters, текущее выбранное значение, результат смены, видимость группы | Потребитель |
| Внешние расстояния, порядок групп, место в toolbar/хедере аккордеона и реакция на доступную ширину | Страница или составной блок |
| Внешний вид счётчика | [B12 tab-count16](<../Счётчик/Контракт.md>); значение/смысл задаёт потребитель, B09 передаёт selected |
| Вкладки B10 с линией и чипсы B08 | Их собственные владельцы; эти семейства не объединены с B09 |

UI получает упорядоченный набор опций и один выбранный ID/режим; при активации передаёт выбранную идентичность родителю. Это роли данных UI, не серверный DTO и не предписание имён props. Для показанного выбранного состояния родитель передаёт ID из набора. Компонент не создаёт независимое сохранённое состояние или неоговорённый fallback при неизвестном ID. Значение по умолчанию выбирает страница, а не B09.

## Варианты

| Вариант | Состав | Применения |
|---|---|---|
| text40 | Подпись и необязательный счётчик; ширина по переданному содержимому | Раздел отчётов на Главной; тип вклада; категории новостей; показатель графика Usage |
| icon40 | Два icon-only элемента «Табличный вид» и «Карточный вид», без label/counter | Главная, каталог отчётов, каталог метрик и связанные метрики отчёта |
| icon-tree40 | «Табличный вид», «Карточный вид», «Дерево» в этом порядке. Все три кнопки показывают только иконки | Каталог источников |
| mailings-mode | Текст без счётчиков, белый выбранный пункт на серой подложке | [Режимы рассылок](<../../../Разделы/Отчёты/Паспорт/Рассылки.md#переключатель-режимов>) |

Размер группы text40 зависит от содержимого. Ширины436/435/442,253 и406 из разных экранов остаются параметрами композиции/набора у родителей. Варианты icon40 и icon-tree40 имеют разные ширины группы из YAML при одинаковом размере кнопок. Figma progress обозначает число элементов исходного семейства.

В icon-tree40 третья кнопка использует [SVG связанной схемы](<../../../Разделы/Источники/assets/Срез 9 ноября/source-tree-view-icon.svg>). Подсказка и доступное имя — «Дерево». На белой активной подложке glyph синий, на неактивной — тёмный. Ресурсы таблицы и карточек общие с icon40. [Состояние с выбранным деревом, 1440×900](<../../../Разделы/Источники/assets/Срез 9 ноября/sources-tree.png>).

Неактивный фон track либо локальный neutral выбирается применением, без изменения выбранного состояния. Подтверждённые исключения: «Изменения» в новостях и inactive-элемент карточного baseline каталога отчётов. Выбранная белая подложка и выбранный цвет сохраняются независимо от разрешённого неактивного фона. DS defaults fade/scrollbar, размеры48/32 и произвольные progress-комбинации не добавляются без подтверждённого применения.

## Механика и состояния

| Условие / событие | Наблюдаемое следствие и граница |
|---|---|
| Родитель передал выбранный ID/режим | Только соответствующий элемент получает selected; остальные сохраняют выбранный применением неактивный фон |
| Нажат другой элемент | Передать его ID/режим родителю; видимый результат определяется возвращённым значением |
| Повторно нажат выбранный элемент | Передать тот же ID, без снятия выбора. Это не checkbox или multi-select |
| text40: ArrowRight/ArrowLeft | Переместить фокус к следующему/предыдущему элементу с переходом через край и передать его ID |
| text40: Home/End | Переместить фокус к первому/последнему элементу и передать его ID |
| icon40 и icon-tree40 | Каждая нативная кнопка имеет доступное имя и aria-pressed. Кнопки доступны через Tab, активируются через Enter/Space. Стрелки внутри группы не переключают выбор |

Текущий text40 использует tablist/tab, aria-selected и один Tab-вход на выбранном элементе. У icon40 и icon-tree40 используется role=group с отдельной Tab-остановкой на каждой кнопке. Glyph декоративен, рамка фокуса видима.

Сверка применения4ноября2026: самостоятельные SegmentedControl и ViewPicker сохраняют CoFo Sans Medium500 и видимый focus без внешней обёртки HomeControls. Внутренние размеры и состояния B09 не зависят от того, встроен ли он в Главную, каталог отчётов, метрик или источников. Внутренние значения YAML не менялись; исправлена потеря насыщенности шрифта при самостоятельном использовании. Сравнение text40 Источников с действующей Главной включено в браузерную регрессию каталога источников.

Состояние ведёт потребитель. Controlled-компонент без возвращённого нового значения сам не меняет выбранность. Смена вида не должна создавать другой набор данных; сохранение фильтров, URL, пагинации, возврата и выбранного объекта определяется соответствующей страницей/путём, а не B09. Он не применяет фильтры и не назначает переход всем опциям по названию.

В Usage выбирается показатель, а не период: набор и отсутствие ряда определяет паспорт отчёта. Пустой ряд индекса значимости не становится disabled-сегментом без отдельного решения. При отсутствии подтверждённого материала «Платформ» родитель сохраняет ограничение этого экрана, не создаёт содержимое автоматически.

## Параметры и статус наблюдений

Геометрия контейнера и item, выбранные/невыбранные цвета перенесены из точных consumers Главной и каталога отчётов. Дополнительные шрифт/letter-spacing, backdrop blur и focus из существующего CSS отмечены observed-snapshot, а не новой визуальной приёмкой.

У Figma item указан gap8; текущая внутренняя обёртка optionContent в CSS имеет gap4. Уровни размещения названы отдельно в YAML; соответствие этой обёртки внутреннему дереву Figma полностью не установлено. Наблюдённый gap4 не заменяет исходный item-gap8 как новую норму. Детальная визуальная приёмка внутреннего label/counter по этому переносу не заявляется. Стили самого счётчика ведёт B12 tab-count16, без второй таблицы его значений здесь.

В исходном consumer подписок1038:22312 белый выбранный Cards и противоположные цвета glyph противоречат друг другу. Это известное отклонение. По принятому решению используется согласованный цвет по текущему выбранному значению, как у640:15431/778:17746/640:23952; обратная раскраска не наследуется. [Исходная сверка](<../../../../references/visual-data/iterations/I09a/view-source-conflict.json>) сохраняет точные item/vector IDs и aliases. Сам PNG подписок остаётся эталоном прочей композиции с этим ограничением.

## Документальная приёмка

Сверить параметры и состояния с CSS и эталоном нужного применения. Сохранить разные клавиатурные роли, inactive-overrides и известное отклонение подписок. В каталоге источников проверить порядок трёх кнопок, однозначную выбранность и сохранение фильтров при переходе из таблицы в дерево. [Браузерный сценарий](<../../../../references/verification/tests/sources-tree.spec.ts>).
