# Пункт боковой навигации

Один переиспользуемый пункт списка C01; «Главная», «Отчёты», «Задачи» и остальные названия — его применения, а не отдельные компоненты. Выделен из [контракта панели](<../../Боковая навигация/Контракт.md>) на П4-01 без изменения продукта. Точные типизированные параметры находятся только в [Параметры.yaml](<Параметры.yaml>); правила выбора и состояния — здесь. Формат и проверка YAML — [общий ресурс](<../../../Ресурсы/Параметры компонентов/README.md>).

## Граница и маршрут

Для сборки пункта прочитать этот контракт, его YAML, нужную строку [конфигурации панели](<../../Боковая навигация/Источники.md#состав-показанной-конфигурации>) и [шрифты](<../../../Ресурсы/Шрифты/README.md>). Если меняется сворачивание всей панели, дополнительно читать её [действующее уточнение](<../../Боковая навигация/Контракт.md#плавность-переходов--уточнение-3-ноября-2026>). Обратная ссылка на панель не требует загрузки всех экранов.

| Ответственность | Владелец |
|---|---|
| Внутренняя геометрия, типографика, визуальные состояния пункта, скрытие его текста | Этот контракт и YAML |
| Девять разделов, их порядок/иконки/counters, текущий section ID и обработка намерения выбора | Панель C01 |
| Ширина/фон/позиция панели, вертикальное размещение списка, граничный шеврон, переключение режима и движение контентной области | Панель C01 |
| Начертания и файлы шрифтов | Общий ресурс шрифтов; YAML ссылается на него токеном |
| Содержимое выбранного раздела, реальные URL, права и получение totals | Внешние владельцы; этим компонентом не определены |

Кнопка границы панели не является вариантом пункта. Поле, checkbox, drag-ручка, status dot и контекстные controls исходного Tree не входят в этот пункт.

## Анатомия и применение

Повторяемая строка содержит область активации, отдельный SVG, подпись и необязательный counter. Внутреннее оформление counter ведёт [B12 navigation-text14](<../Счётчик/Контракт.md>); четыре прежних параметра YAML разрешаются ссылками к B12, а gap/видимость/режим остаются у B11/C01. У подписи и counter свои текстовые области; родитель передаёт содержимое, а не вставляет готовую копию разметки девяти пунктов.

| Вход по смыслу, не обязательное имя API | Настройка применения |
|---|---|
| section ID | Стабильная идентичность; selected сравнивается с текущим ID, не с индексом массива |
| label | Подпись и доступное имя кнопки; берётся из конфигурации C01 |
| icon | Отдельный SVG конкретного раздела из ресурсов C01; один источник в обоих режимах |
| counter | Необязательная отображаемая строка; отсутствие не означает ноль. Значения примера не константы |
| current | Соответствие текущему разделу; сохраняется при смене режима панели |
| mode | expanded либо collapsed от C01; пункт не хранит отдельное независимое состояние панели |
| activation | Передаёт выбранный section ID внешнему владельцу; адрес/загрузка страницы не изобретаются |

**Два разбора применения.** На Главной C01 передаёт текущий ID Главной, её label/icon и отсутствие counter; у Отчётов передаёт другой ID/icon и пример counter. При добавлении «Задач» третьей строкой выбранность Главной/Отчётов сохраняется по ID. На экране Метрик C01 передаёт ID Метрик; сворачивание скрывает текст, а раскрытие возвращает Selected тому же пункту. Число строк и их порядковый сдвиг не меняют это соответствие. Содержимое страницы «Задачи» и её URL по наличию пункта не объявляются готовыми.

## Геометрия и состояния

Действует постоянная внутренняя сетка из YAML: glyph и начало подписи сохраняют координаты во всех промежуточных кадрах сворачивания. Иконка не уменьшается, строка не центрируется заново, текст не перемещается через transform. Пункт обрезает правую часть содержимого при сужении доступной области. Внешний отступ строки и её внутренний inset различаются; их нельзя сложить повторно при вложении в C01. Параметры с `page-x` — проверяемые координаты при panel x0, а не второй CSS-отступ.

| Вариант / состояние | Условие | Результат |
|---|---|---|
| expanded / default | ID не текущий, указатель вне пункта | Подпись/counter видны, прозрачная подложка |
| expanded / selected | ID текущий | Подложка selected; те же размер/начертание, не отдельная копия компонента |
| expanded / hover | Указатель над невыбранным пунктом | Hover-подложка из настроенного локального семейства; геометрия не меняется |
| expanded / selected-hover | Указатель над выбранным пунктом | Отличная от обычного hover подложка; current ID сохраняется |
| collapsed / default или current | Панель свёрнута | Glyph остаётся на месте, постоянной selected-заливки нет; текущая идентичность остаётся в aria-current |
| collapsed / hover | Указатель над пунктом | Круг под закреплённой иконкой; круг не заменяет прямоугольную область активации и не сдвигает её |

Варианты expanded/collapsed — геометрия отображения, current и hover — независимые признаки. В YAML числовые значения base наследуются вариантом; состояние переопределяет только названные параметры. Другие темы/режимы цвета, Editing, drag, disabled/loading/error и tooltip не выводятся из наличия одноимённых мастеров.

Цвета expanded hover/selected-hover подтверждены сохранёнными мастерами и используемыми стилями прототипа. Цвет collapsed hover имеет статус наблюдаемой реализации в источнике `implementation`; отдельная пользовательская визуальная приёмка позднего уточнения не заявлена. Это сохранение существующего среза, не утверждение нового общего токена для всех кнопок системы.

## Действия, скрытие и доступность

1. Активация пункта передаёт его section ID; C01 меняет текущий раздел в своей границе. Enter/Space сохраняют семантику используемой кнопки. Реальный destination, права и сохранение после перезагрузки этим контрактом не определены.
2. Сворачивание не меняет ID и SVG. Подпись и counter остаются в DOM; закрытие завершает затухание и скрывает их через visibility. В закрытом режиме текст aria-hidden=true, у кнопки остаётся доступное имя и aria-current текущего раздела. Скрытые подписи не дублируются в доступном имени.
3. Раскрытие возвращает текст с указанной в YAML задержкой. Его ширина постоянна: counter не толкает начало подписи при сужении. Быстрое обратное переключение не блокируется ожиданием анимации.
4. Hover меняет фон без изменения размеров. При prefers-reduced-motion:reduce декоративные переходы отключаются, конечные состояния и доступные имена сохраняются. Ширина и её анимация принадлежат панели.
5. Focus не должен теряться при сворачивании. Текущая техническая focus-outline реализации описана её источником; перенос этой порции не утверждает общий focus-токен кнопок или новые клавиши навигации по списку.

## Проверка и границы готовности

При документальной приёмке проверяются схема YAML, соответствие чисел исходным фактам/позднему решению, два разбора применения по ID, достижимость и неизменность ресурсов/источников. После реализации отдельно сравниваются размеры, состояния и отсутствие смещения во время всего перехода, сохранение current, accessible names и reduced-motion. Документальная приёмка не заменяет эти проверки кода и визуальную приёмку пользователя.

Не определены реальные маршруты/права/totals, persistence, неизвестные состояния и дополнительные темы. Они ограничивают соответствующее применение, а не требуют создавать догадки в общем компоненте. Изменение внутреннего стиля/механики ведётся здесь/YAML с проверкой затронутых применений C01; изменение состава/порядка разделов ведётся в C01.
