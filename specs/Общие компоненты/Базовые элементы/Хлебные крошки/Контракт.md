# Хлебные крошки

П4-12 · B15. Документальная декомпозиция 4 ноября 2026. Общий владелец внутреннего оформления и устройства крошек; точные параметры — [Параметры.yaml](<Параметры.yaml>), их разрешение и проверка — [общий формат](<../../../Ресурсы/Параметры компонентов/README.md>). Срезы Figma/Paper и наблюдения CSS не объявляются новой приёмкой работающего интерфейса.

## Состав и ответственность

Подтверждённая композиция содержит один родительский пункт, декоративный разделитель вправо и текущую подпись. Родительский пункт допускает возврат через предоставленное намерение onBack. Текущая подпись — текст, отдельного действия у неё нет. Объектное название находится в соседнем заголовке страницы; оно не подставляется автоматически вместо «Паспорта отчёта», «Паспорта показателя» или «Карточки источника».

| Вариант | Потребитель | Конфигурация, которой владеет потребитель |
|---|---|---|
| report20 | [Паспорт отчёта](<../../../Разделы/Отчёты/Паспорт/Контракт.md>) | «Отчёты» → «Паспорт отчёта», выбранный отчёт и сохранённый список |
| metric20 | [Метрики и показатели](<../../../Разделы/Метрики и показатели/Контракт.md>) | «Метрики и показатели» → «Паспорт показателя», выбранный объект и контекст входа/возврата |
| source20 | [Детальная карточка Источника](<../../../Разделы/Источники/Детальная карточка/Контракт.md>) | «Источники» → «Карточка источника», выбранный источник и параметры каталога; принят только этот внутренний компонент |

По прямому уточнению пользователя4ноября source20 приведён к геометрии отчёта: внутренняя nav высотой20px с интервалом4px. Ранее использованные min-height20/gap8 по Paper относятся к предыдущему срезу. metric20 наследует текущий цвет от .detail; B15 не придумывает отдельный цвет последней подписи. В report20/metric20 вес текста наследуется. Для source20 исходный контракт требует Regular400; текущий CSS получает его наследованием. CSS нормализует button через font:inherit, CoFo Sans берётся из общего ресурса. Новый локальный файл шрифта не создаётся.

Последним прямым поручением пользователя4ноября отдельная круглая стрелка перед крошками удалена во всех трёх паспортах. Родительский текстовый пункт вызывает прежний onBack с восстановлением контекста. Внешний ряд и расстояния до заголовка остаются у паспорта; внутренний декоративный chevron-right сохраняется и не становится кнопкой возврата.

Внешний ряд сохраняет минимум24px и8px до ряда заголовка. Промежуточное решение4ноября о корпусе24×24/glyph12×12 отменено последним поручением об удалении отдельной стрелки; эти размеры не требуют выводить кнопку снова. Общая геометрия ряда и типографика заголовка/description вынесены в [DetailHeader](<../../../../references/implementation/components/DetailHeader/DetailHeader.module.css>). Внутренние nav20/gap4, декоративный разделитель16px и обработчики возврата сохранены. Это правило внешней композиции, а не изменение размеров внутренних крошек B15.

## Действия и состояние

| Элемент / условие | Подтверждённый результат | Граница владельца |
|---|---|---|
| Родительский пункт активирован мышью либо нативной кнопкой Enter/Space | Передаётся onBack. B15 не выбирает адрес, объект или набор параметров | Нынешний код использует button type=button; маршрут, прямой вход, reload и восстановление списка определяет потребитель |
| Текущая подпись | Отображается как текст текущего вида страницы | Не кнопка, не отдельная ссылка на выбранный объект; её роль не выводится из цвета |
| Разделитель | Показывается chevron-right с пустым alt, отдельного действия нет | Используется полный SVG, а не стрелка сворачивания Accordion или круглая кнопка «Назад» |
| Отдельная круглая кнопка возврата | Не отображается по последнему поручению4ноября | Возврат остаётся у родительского текстового пункта |

У отчёта возврат восстанавливает сохранённый список; без такого списка прямой вход возвращает в каталог отчётов. Метрики сохраняют свой контекст, включая переходы из связанных объектов; правила родителей не заменяются безусловным переходом в самостоятельный каталог. Источники сохраняют вид, применённые условия и страницу; прямой вход без истории ведёт в каталог. B15 не хранит URL/историю, не рассчитывает дерево разделов и не владеет выбранным ID. Эти последствия читаются из документов потребителей; демонстрационный маршрут не становится серверным API.

В навигации текущего кода задан aria-label «Хлебные крошки»; декоративные img имеют alt="". У source20 текущий span получил aria-current=page в уточнении SD01; для остальных потребителей это внедрение не заявляется. Не добавляются произвольные промежуточные звенья, dropdown, сворачивание пути, многоточие, hover/selected/disabled-оформление или особые Arrow/Home/End-переходы. Клавиатура вкладок B10 не переносится на крошки. Подтверждённого правила переноса/усечения длинных звеньев нет; длина имени объекта не повод расширять статическую последнюю подпись. Native button остаётся доступным стандартной клавиатурной активации; отдельная продуктовая геометрия focus не установлена.

Самостоятельные разделители: [breadcrumb-chevron.svg отчёта](<../../../../assets/images/report-detail/chrome/breadcrumb-chevron.svg>) и [chevron-right.svg метрики](<../../../../assets/images/metrics/detail/chevron-right.svg>), каждый16×16, viewBox0 0 16 16. Рисунок и цвет принадлежат SVG; одинаковое содержимое не требует перемещения файлов или утраты их входящих ссылок. Источник использует первый файл. Это implementation-ресурсы, а не вырезки экрана; точный исходный Figma-node отдельного glyph не установлен, поэтому ссылка на соседнюю иконку ему не назначается.

Дизайн-система используется только как источник. Привязка к библиотечному Breadcrumb и импорт компонента не подтверждены; похожее имя не заменяет проверенные варианты. У всех Figma-ссылок сохраняются nodeId и статус unverified-live: этот перенос опирается на имеющиеся срезы, не на новую проверку живой версии. Наблюдения CSS в YAML помечены observed-snapshot, утверждённые решения владельцев сохраняют приоритет над старым PNG.

## Приёмка

1. Для каждого потребителя находятся общий контракт, его вариант YAML, ресурс разделителя и эталон того же контекста.
2. Сохраняются подписи звеньев и их разные роли: первый интерактивен, последний текстовый, разделитель декоративен. Родительский callback не заменяется придуманным URL.
3. Проверяются размеры/интервалы/типографика/цветовые источники по YAML и CSS; внешний ряд и кнопка не сливаются с внутренней nav. Высота внутренней source20 равна20px по уточнению SD01; внешний ряд сверяется по [композиции паспорта](<../../../Разделы/Источники/Детальная карточка/Контракт.md#геометрия-и-оформление>), без второй числовой нормы в проверке B15.
4. Проверяются схема, сохранность исходных Figma URL и файлов, SVG/viewBox, локальные ссылки/якоря и правила контекста без обращения к чату. Это приёмка документации, не новый runtime-прогон или подтверждение всей страницы.

Автономная копия и её ресурсы проверяются отдельно на П7. Текущая порция не меняет приложение, дизайн-систему, Project Context или макеты.
