# Визуальные эталоны фильтрации

## Текущие маршруты и границы сверки

Сначала выбрать владельца: [панель](<Панель.md>) или [меню колонки](<Меню колонки.md>). Ниже прямые PNG для названного состояния; Figma для текущей сверки не обязательна. Наблюдаемая реализация не отменяет принятое правило, а PNG не является ассетом UI или доказательством исполнения действия. Источники1–2ноября ниже сохраняют происхождение, но не конкурируют с поздними multiple/range/status/position-решениями.

Для c1 [README](<../../Ресурсы/Срез прототипа/README.md>)/[manifest](<../../Ресурсы/Срез прототипа/manifest.json>) фиксируют версию, исходный hash, viewport, setup-actions и SHA256 кадров. Дополнительные PNG4ноября сохраняют свои README/условия и не объявляются автоматически байтовыми кадрами общего manifest. Подписи выбранных значений берутся из собственного набора данных; одинаковая подпись не доказывает идентичность. Отсутствующие сочетания не объявлены снятыми только потому, что снят один представитель.
