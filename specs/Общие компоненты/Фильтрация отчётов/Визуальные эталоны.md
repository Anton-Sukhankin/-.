# Визуальные эталоны фильтрации

Актуализация параметров и визуальных эталонов: 2 ноября 2026. Исторические даты подготовки ниже сохраняют свой срез; параметры и PNG проверяются по обновлённым манифестам.
Срез02.11.2026,экспорт scale1. Каждый PNG — read-only экспорт точного узла; размеры исходного узла,итогового PNG и SHA256 находятся в [manifest](<assets/manifest.json>). Из-за тени raster меню больше исходных bounds. Снимки показывают текущий макет,не исполнение переходов. Наборы значений демонстрационные. [Контракт](<Контракт.md>) имеет приоритет при отмеченных отклонениях.
