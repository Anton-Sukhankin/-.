# Аккордеон

Срез3ноября2026. Общий компонент для паспорта отчёта и паспорта метрики по прямому решению пользователя: одна реализация и механика, различается содержимое. Оба фактических потребителя проверены. На проход исправления шапки отчёта и hover аккордеона единственный владелец общих файлов — координатор текущей реализации; «Figma / A» подтвердил отсутствие параллельной записи. Владение для следующих поручений определяется до начала изменений.

## Контракт

[AccordionProps и реализация](<../../../references/implementation-current/components/Accordion/Accordion.tsx>) и [общие стили](<../../../references/implementation-current/components/Accordion/Accordion.module.css>) — единственные исполняемые владельцы механики. Потребители не создают копии toggle/aria/CSS. Пример потребителя: [паспорт отчёта](<../../Разделы/Отчёты/Паспорт/Контракт.md>). При новом варианте согласовать общий параметр и проверить всех фактических потребителей.

| Вход | Назначение |
|---|---|
| title,description? | Заголовок и необязательное пояснение |
| count? | Число в базовом [B12 tab-count16](<../Базовые элементы/Счётчик/Контракт.md>) либо строковая muted-подпись C09; с action count размещается отдельно справа, без дублирования |
| icon? | Необязательная декоративная иконка справа от текста |
| action? | Отдельное действие рядом с кнопкой раскрытия; не вложено в неё |
| wrapAction? | Позволяет действию раскрываемой секции перейти на отдельную строку при ширине окна до 1100 px |
| children | Содержимое секции, без знания сущности родителя |
| open?,onOpenChange? | Управляемое состояние и уведомление о намерении изменить его |
| defaultOpen? | Начальное локальное состояние; по умолчанию раскрыт |
| variant? | Визуальный вариант report или metric; по умолчанию report |
| chevronSize? | Диаметр круга32или40px; по умолчанию32 |
| chevronIcon? | Необязательная точная иконка закрытого состояния; общий компонент поворачивает её на180° при раскрытии, без собственного обработчика потребителя |
| collapsible? | По умолчаниюtrue; false включает статичную секцию с теми же шапкой, разделителем, радиусом и телом, без кнопки раскрытия |
| leadingIcon? | Тематическая декоративная иконка статичной секции внутри круга32px, с теми же цветами, что у общей стрелки |
| bodyInset? | default сохраняет отступ16px24px; table задаёт16px для вложенного табличного контейнера; flush убирает отступы и радиус тела для матрицы, примыкающей к границам секции |

Нажатие заголовка меняет раскрытие только его секции. Кнопка поддерживает Enter и Space, aria-expanded и aria-controls. Когда передан open, родитель определяет фактическое состояние, обработчик получает новое значение. Без open компонент хранит локальное состояние. Закрытое содержимое сохраняется в DOM; на закрывающейся обёртке сразу установлены inert и aria-hidden, поэтому её элементы недоступны фокусу и исключены из дерева доступности. После перехода обёртка также получает visibility:hidden и нулевую высоту. Режим «только одна секция раскрыта» не вводится автоматически. Начальный набор раскрытий задаёт родитель через open/defaultOpen.

В списках внутри аккордеонов детальных карточек нижний разделитель ставится только между соседними элементами. У единственного или последнего элемента нижнего разделителя нет. [Браузерная проверка](<../../../references/verification/tests/metrics.spec.ts>).

### Плавное раскрытие — решение 4 ноября 2026

По прямому поручению пользователя общая реализация раскрывается и сворачивается плавно: переход высоты через grid-template-rows 0fr/1fr длится320ms с cubic-bezier(.22,1,.36,1), прозрачность —200ms ease. Стрелка поворачивается за320ms с той же кривой. Высота определяется содержимым, фиксированного max-height нет; при изменении ширины конечная геометрия остаётся естественной. Повторное нажатие разворачивает текущий переход без таймеров размонтирования или потери содержимого.

При prefers-reduced-motion:reduce переходы раскрытия, прозрачности, видимости и стрелки отключены; состояние меняется сразу. Начальная отрисовка не проигрывает раскрытие. Статичные секции collapsible=false не получают анимированную обёртку. Конечные отступы, рамки, цвета, open/defaultOpen и независимость секций сохраняются. Обёртка анимации добавлена только внутри общего Accordion; потребители её не копируют.

Проверка4ноября: npm run check — типы,29unit и сборка;16браузерных сценариев отчёта/источников/Usage/метрик и анимации пройдены. Адресная проверка requestAnimationFrame подтвердила промежуточные высоты обоих направлений и нулевую конечную высоту закрытия; проверены Enter/Space, быстрые повторные переключения, controlled-метрика и reduced motion. Это техническая проверка реализации, а не отдельная пользовательская визуальная приёмка.

Уточнение4ноября по сводной статистике использования: bodyInset=flush сохраняет верхний разделитель тела, но делает его прямым от края до края. Контент отвечает за внутренние линии своей матрицы; наружный нижний бордер рисуется только общей секцией. Остальные потребители сохраняют прежний default/table, размеры и механизм раскрытия.

Контейнер заполняет доступную ширину; min-width:0 допускает перенос длинного названия. По отчётному эталону: border1px #d6e6fb, radius12px, header padding14px16px, gap12px; chevron32px; title16/20px500, description12/16px400; body padding16px24px и line-height20px. Единицы px. Отдельного текста с названием компонента внутри секции нет. По согласованному запросу координатора метрики добавлен variant="metric":header12px16px, title16/22px, description12/18px без промежутка (одно короткое название с описанием занимает40px, header64px); body14/22px #101d3b, border#d7e6f5, muted#52698c, фон круга#f0f2f5. У секций «Полное описание», «Формула расчёта» и «Бизнес-вопросы» потребитель задаёт chevronSize={40}, остальные сохраняют32. Цвет стрелки метрики#101d3b. Разделитель тела метрики выполнен inset-линией и не добавляет1px к высоте потока. Длинное название увеличивает высоту, а не обрезается до44px. Эти различия заданы переменными внутри единого CSS, а не второй реализацией механики. Источники: 1167:28025 и 1190:30570, свежий high-fidelity контекст3ноября2026.

## Доказательства

Уточнение4ноября: статичный режим используется в динамике и истории вкладки «Использование». Его содержимое всегда видно; у статичной шапки нет aria-expanded, скрытого состояния и имитации кнопки. action остаётся отдельным интерактивным слотом. Шапка может перенести действие при нехватке ширины, не сжимая текст до исчезновения. Старые потребители сохраняют collapsible=true, прежние отступы и поведение. Сопоставление и регрессионная проверка отчёта/метрики. Отдельная копия шапки для новых секций не создаётся.

Проверка отчётного потребителя включает переключение кнопкой и Space, сохранение доступности при resize. Controlled и локальный режимы проверены на общем стенде вариантов:клик, Enter/Space, независимость, размеры/цвета, перенос текста и отчётная композиция. Стенд не означает приёмку всего паспорта метрики; последующая проверка её действующего потребителя и общей стрелки приведена ниже.

Уточнение того же среза: generated context ошибочно передал heading44px/gap4. Независимое чтение фактических узлов1167:28025–28028 подтвердило heading40/gap0/header64 и внутренний stroke; эти фактические размеры приоритетны. На однострочном блоке проверена итоговая высота120px (outer2+header64+body16+22+16). Старые доказательства слота chevronIcon описывают предыдущий срез; действующая общая стрелка определена ниже.

## Общая стрелка и hover — уточнение 3 ноября

В отчёте и метрике используется один SVG из мастера947:23085, root16×16px. Проверенный экземпляр метрики связан с тем же мастером; отдельной картинки стрелки в её потребителе больше нет. Мастер локальный в файле Figma; привязка к опубликованной удалённой библиотеке этим не утверждается. Точная геометрия применяется как CSS mask с currentColor; закрытое состояние направлено вниз, раскрытое повёрнуто на180°. Диаметр круга32/40px и размер glyph16px при hover не меняются. Слот chevronIcon остаётся необязательным API, но оба текущих потребителя используют общий default.

По прямому поручению пользователя при наведении на заголовок и при клавиатурном focus-visible фон заголовка остаётся белым. Круг стрелки получает #e7f2ff, стрелка — #007bfc; серой заливки всего заголовка нет. Переход background-color/color160ms ease; prefers-reduced-motion отключает его. Это согласованное уточнение интерактивного состояния, исходные Figma/PNG не переписываются.

Сверка с Figma и обоими потребителями: точная форма стрелки, цвета hover, Enter/Space и независимое раскрытие; геометрия12 секций метрики сохранена.


## Рамка всей секции при наведении · решение4ноября2026

При наведении на любую часть Accordion его внешняя рамка использует [общий цвет рамки карточек](<../Карточки отчётов/Контракт.md#рамка-при-наведении>). Правило действует для вариантов report и metric в свёрнутом, раскрытом и статичном состояниях. После ухода курсора возвращается исходный цвет варианта. Переход border-color занимает 160 мс с ease. При prefers-reduced-motion:reduce цвет меняется сразу.

Меняется только цвет существующей внешней линии1px:ширина/высота,отступы,радиус12px,белый фон и внутренний разделитель тела сохраняются. Hover круга/стрелки заголовка и клавиатурный focus-visible продолжают действовать по правилу выше. Наведение на тело само по себе не раскрывает/сворачивает секцию и не делает его кнопкой; вложенные действия сохраняют свои назначения.

Потребители общего правила:Обзор и Слайды отчёта,Источники данных,Использование (включая статичные секции), полные паспорта метрик и описание полей детальной карточки источника. Локальные копии стилей hover в потребителях не вводятся. Проверка:наведение на заголовок,тело и доступные действия,уход курсора,отсутствие изменения геометрии и сохранение независимого раскрытия.

## Метаданные заголовка · SD01

Необязательный слот `metadata` размещает неинтерактивные метаданные под заголовком; перенос элементов разрешён, промежуток4px, отступ от заголовка8px. Он не содержит вложенных кнопок и не меняет назначение, клавиатурное управление или механику раскрытия общего Accordion. Без слота прежние потребители сохраняют результат. Цвета и состав технических тегов полей определяет [детальная карточка источника](<../../Разделы/Источники/Детальная карточка/Контракт.md>), а не общий компонент. Новая композиция и регрессия старых потребителей проверены в SD01.
