## Поздние решения и граница действий

Позднее решение пользователя4ноября2026: рисунок сущности отчёта унифицирован по эталонной иконке боковой навигации. Действует [единый контур и правила размеров/состояний](<../../../context/target/Требования и границы.md#единая-иконка-отчёта--решение-4-ноября-2026>); старые SVG/PNG ниже описывают исходный срез, runtime-варианты получаются из одного навигационного мастера.

Позднее решение4ноября2026: значения платформ и пример динамики MAU в работающем прототипе уточнены по поручению пользователя. Действующий набор и границы ведёт [Демонстрационные данные отчётов](<../../../context/target/Демонстрационные данные отчётов.md>); прежние значения Figma/PNG ниже сохраняют исходный срез.

**Локальное следствие:** выбор строки передаёт намерение открыть именно этот отчёт; действие карандаша передаёт отдельное намерение редактировать его. Ни одно не означает открытие BI, выдачу прав или успешное изменение данных. Историческая рабочая заметка1295:147411 исключена из эталонов.

## Состояния и действия

| Начальное условие | Действие / событие | UI-результат или передаваемое намерение | Граница / выход |
|---|---|---|---|
| Строка Default | Наведение | State=Hover: синяя рамка,подложка документа#E7F2FF,его контуры#0067DC; набор данных и размеры прежние | MOUSE_LEAVE возвращаетDefault,включая подложку#EEF2F6 и контуры#7186A5; reactions сохранены,Present не проигрывался |
| Доступен конкретный отчёт | Выбор строки просмотра | Намерение открыть паспорт этого объекта | Не редактор и не BI; адрес,права и сохранение позиции задаются интеграцией/путём R-01 |
| Кнопка карандаша строки | Нажатие | Отдельное намерение редактировать этот отчёт | Админка вне объёма; destination и успешное сохранение не определять по наличию иконки |

Намерение строки просмотра и карандаша должны различать идентичность отчёта и тип действия. Конкретный способ обработки вложенного клика не задан Figma, но нажатие карандаша не должно одновременно трактоваться как открытие паспорта. В исследованном мастере строки reaction только Hover; присутствие картинки паспорта не означает подключённый клик каждого экземпляра.

## Данные одной записи

Для строки необходимы: отображаемое название; признаки проверки, если они предусмотрены данными примера; MAU, его отображаемая динамика и графический ряд/ресурс; платформа,домен,мастер-система; имя владельца и допустимое изображение/заглушка; последнее отображаемое использование. Формула MAU, вычисление динамики и подтверждение пользователя по фотографии не проектируются таблицей. Индикаторы статуса остаются внутри колонки Отчёт, отдельная статусная колонка не появляется.

Для локальных demo-отчётов приоритеты идентичности, домена и проверки определяет [владелец согласованного набора](<../../Разделы/Главная/Контракт.md#единый-набор-избранных-отчётов--решение-3-ноября-2026>). Таблица получает статус этого объекта, а не присваивает проверку всем строкам по зелёным индикаторам исходного PNG. Красный индикатор независим; его связь с проверкой и MAU не установлена. Состав текущего контекста не меняется от использования общего компонента.
