# Опции в таблице CRM

Компонент занимает последнюю колонку [таблицы CRM](<Карточка CRM.md#результаты-и-пагинация>). Сохраняет порядок предоставленных значений, отображает каждую опцию в виде «код — значение».

| Число значений | Свёрнутая строка | Раскрытая строка |
|---|---|---|
| 0 | Прочерк. Резерв под вторую строку. | Раскрытие недоступно. |
| 1 | Одно значение. Резерв под вторую строку. | Раскрытие недоступно. |
| 2 | Два значения. | Раскрытие недоступно. |
| Больше 2 | Первое значение и кнопка «Ещё N значений». N равно числу опций минус один. | Все значения целиком, длинный текст переносится. Под списком кнопка «Свернуть». Высота строки увеличивается по содержимому. |

Одна круглая кнопка в заголовке «Опции» переиспользует [круглую кнопку с иконкой](<../../Общие компоненты/Базовые элементы/Кнопка/Контракт.md>). Локальная подложка `#E8EBF0` размером 20×20 px, шеврон 12×12 px, зазор от заголовка 12 px. Кнопка доступна, если в текущей порции есть хотя бы одна строка с числом опций больше двух. При отсутствии раскрытых строк нажатие раскрывает все подходящие. При наличии хотя бы одной раскрытой строки нажатие сворачивает все раскрытые. Доступное имя сообщает предстоящее действие. В режиме «Без пагинации» область действия охватывает всю применённую выдачу.

Одиночное и общее управление используют одинаковый переход высоты за 320 мс. При этом соседние строки плавно смещаются. Системное уменьшение движения отключает переход. Условия сброса раскрытия ведёт [карточка CRM](<Карточка CRM.md#результаты-и-пагинация>).
