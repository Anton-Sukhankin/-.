# Чипсы условий CRM и их редакторы

Компонент занимает правую группу [компактной панели](<Панель поиска CRM.md>). Один чипс соответствует одному непустому текстовому критерию черновика. Основной запрос остаётся в поле поиска, переключатели остаются в левой группе. Порядок ведёт [контракт критериев](<Панель поиска CRM.md#критерии>), размеры и типографику — [параметры чипсов и редакторов](<Параметры чипсов CRM.yaml>).

Видимый чипс показывает краткую подпись и значение. Слева шеврон, справа отдельная кнопка удаления. Если подпись не помещается в `chip-text-max-width`, она обрезается многоточием. При наведении на обрезанный текст [общая подсказка](<../../Общие компоненты/Текстовые подсказки/Контракт.md>) раскрывает полное введённое значение. Текст чипсов и «Ещё N» имеет те же параметры шрифта, что переключатели слева. Наведение на подпись подсвечивает весь чипс. Наведение на кнопку удаления даёт круглую подсветку внутри области кнопки. При открытом редакторе чипс сохраняет выделенный фон, шеврон повёрнут вверх.

Если условия не помещаются, резервируется место для «Ещё N» с фактическим числом скрытых условий. Каждый следующий чипс уходит в список целиком. Первый может сжаться, чтобы поместиться рядом с кнопкой. При изменении доступной ширины или условий набор пересчитывается.

| Действие | Поведение редактора и фокус |
|---|---|
| Нажать видимый чипс | Открывается одиночный редактор под чипсом. Фокус в поле. Сохраняется исходное значение поля на случай отмены. |
| Нажать «Ещё N» | Открывается список скрытых условий. При доступной ширине его правый край совпадает с правым краем кнопки. Фокус на первом условии. |
| Нажать условие в списке | Редактор открывается внутри той же поверхности. Редактируемая строка выделена серой подложкой. Одновременно активен один редактор. |
| Клик вне, повторный клик по чипсу или выбор другого чипса | Текущий редактор закрывается с сохранением черновика. Другой редактор начинает со своего значения. При выходе из поповера по Tab черновик сохраняется, фокус возвращается к доступному триггеру. |
| «Отмена» или Escape в редакторе | Восстанавливается только исходное значение открытого поля. Фокус возвращается к чипсу. Для вложенного редактора фокус возвращается к строке, а список «Ещё N» остаётся открыт. Escape в списке закрывает его и возвращает фокус к кнопке. |
| Нажать отдельный крестик | Очищается один критерий черновика. Его редактор не открывается. Остальные условия и применённая выдача сохраняются. |

Оба редактора помещаются в пределах окна и находятся над таблицей. Предпочтительные ширины заданы параметром `popover-width` для `direct-editor` и `overflow-editor`. Подпись расположена над полем, справа от поля нейтральная кнопка «Отмена». «Применить» находится на панели поиска и работает по её контракту. Если значение очищено внутри редактора или окно меняет ширину, якорь, текущий ввод и фокус сохраняются до выхода из редактора.
