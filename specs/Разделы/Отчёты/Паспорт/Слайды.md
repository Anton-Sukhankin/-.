# Отчёт · Слайды

[Общая сборка паспорта](<Контракт.md#сборка-паспорта>) · [Раскрытый слайд](<../../../Ресурсы/Проверка сборки/report-slides.png>)

Слева список [аккордеонов](<../../../Общие компоненты/Аккордеон/Контракт.md>), справа общие [«Сведения»](<Сведения.md>). Вкладка получает слайды выбранного отчёта в переданном порядке. Каждый слайд передаёт заголовок, описание и список пар «показатель — значение». Аккордеоны раскрываются независимо. У сводного примера все слайды изначально закрыты. У десяти дополнительных демонстрационных отчётов первый открыт.

| Список слайдов | Счётчик вкладки | Видимый результат |
|---|---|---|
| Передан с записями | Переданный итог, при его отсутствии — число строк | Аккордеоны по числу переданных строк |
| Передан пустым | 0, если отдельный итог не предоставлен | «У отчёта пока нет слайдов» |
| Не передан | Скрыт, если отдельный итог не предоставлен | «Слайды отчёта недоступны» |

В двух последних случаях используется [пустое состояние](<../../../Общие компоненты/Базовые элементы/Пустое состояние/Контракт.md>) с пояснением «В этой вкладке отображаются слайды, связанные с отчётом.». Переданный итог может отличаться от числа доступных строк. Примеры слайдов показывает [демонстрационный набор паспорта](<Контракт.md#демонстрационное-наполнение--6-ноября-2026>).
