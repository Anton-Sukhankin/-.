Показанные метки карточек — «Новое», «Важно», «Изменение»; подписи сегментов имеют собственную грамматику «Важное»/«Изменения». Не вводить автоматическое снятие «Новое» после чтения и не удалять полный текст ради подгонки. Перенос заголовков/анонсов нужно сравнивать с соответствующим consumer при высоте300; не брать ширину258 мастера для рабочей сетки360.

## Действия и данные

Текущая карточка передаёт `onRead` с ID этой новости при активации «Читать» либо области карточки; полное значение title/summary доступно по существующему правилу обрезанного текста.

## Исходные наблюдения

Границы и дата исторических наблюдений — [у модуля](<Новости.md#границы-исторических-наблюдений>); последующие правила и текущие обработчики читаются с указанным там приоритетом.

| Информация / действие | Показанное значение или intent | Предел |
|---|---|---|
| Новость списка |Идентичность, категория, заголовок, анонс, дата, изображение |Не создавать backend DTO или постоянный набор из9 публикаций |
| «Читать» / выбор карточки |Намерение прочитать именно эту новость |В исходных471:2342/2343 реакции не найдены; в текущей демонстрации onRead передаёт точный ID и открывает его материал |
