# Главная · Домены отчётов

Сегмент «Домены» расположен между «Избранными» и «Моими подписками» на вкладке «Отчёты». [Главная](<Контракт.md>) владеет переключателями и навигацией между сегментами.

## Сетка и список

- На входе показывается прокручиваемая сетка доменов на серой подложке. Управление видом появляется при открытии домена с отчётами. Карточка домена переиспользует поверхность и подложку иконки из [карточки отчёта](<../../Общие компоненты/Карточки отчётов/Контракт.md>). Слева иконка доменной группы, справа название и число отчётов с правильным окончанием. Вся карточка открывает домен. Подсказка доступна при фактическом обрезании названия.
- На ширине до 1000 px сетка имеет одну колонку, от 1800 px — три, между ними — две. Отдельной шапки группы над карточками нет. Выдача прокручивается внутри подложки.
- Внутри домена вместо сетки отображаются хлебные крошки «Домены → название домена» и отчёты без повторной группировки. Начальный вид табличный. Сортировку и фильтры задают через заголовки колонок в таблице. Оба вида используют одну порцию данных с теми же идентификаторами, фильтрами и порядком. Правила значений, сортировки и сброса следуют [общему контракту фильтрации](<../../Общие компоненты/Фильтрация отчётов/Контракт.md>). Общий поиск в хедере сохраняет свой [сквозной охват](<../../Общие компоненты/Поиск и навигатор/Контракт.md>).
- Смена домена очищает условия и возвращает первую страницу. Изменение фильтра также возвращает первую страницу. Пагинация применяется после фильтрации и сортировки. Крошка «Домены» возвращает к сетке. Открытие отчёта сохраняет исходный маршрут списка. Крошка домена или Back возвращают к тому же домену, виду и странице.

## Данные и состояния

Карточке нужны название домена и число отчётов в группе. Для списка используются обычные записи отчётов. Домен группирует доступный набор отчётов и учитывает каждый ID один раз. Для локального примера каталог дополнен двумя позициями из «Избранного». Это позволяет открыть «Статус строительных проектов» в «Строительстве» и «Загрузка команды» в «Управлении персоналом». В демонстрации без расширенной пагинации видно шесть доменов, в «Гостеприимстве» пять отчётов.

| Условие | Видимый результат |
|---|---|
| Наборы для сетки загружаются | «Загрузка доменов…» |
| Загрузка одного из наборов не удалась | «Не удалось загрузить домены», действие «Повторить» |
| Доступных доменов нет | «В каталоге пока нет доменов» |
| Прямая ссылка содержит неизвестный домен | «Домен не найден», крошка возвращает к сетке |
| В выбранном домене фильтры исключили все строки | «Отчёты не найдены» и «Сбросить фильтры». Крошки и переключатель вида остаются доступны. Сброс возвращает результаты этого домена. |

Маршрут прототипа начинается с `section=home&segment=domains`. Выбранный домен добавляет `reportDomain`, номер после первой страницы — `domainPage`. Это способ воспроизвести состояние, а не контракт серверного маршрута.
