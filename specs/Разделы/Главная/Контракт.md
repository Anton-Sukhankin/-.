## 1. Граница и владельцы

Главная собирает текущий пользовательский контекст: тип содержимого, сегмент отчётов, вид списка, группы, данные и состояние фильтрации. Она не равна самостоятельному каталогу отчётов. Выбор «Избранные» не должен превращать текущий набор во все отчёты.

| Владелец | Что Главная получает / сохраняет |
|---|---|
| [H-01…H-04](<../../../context/target/Пользовательские пути/Главная.md>) | Сквозные цели просмотра избранного, фильтрации, подписок/вклада и чтения новости. Здесь только локальные композиции и свидетельства |
| [FL-01 / FL-02](<../../../context/target/Пользовательские пути/Фильтрация отчётов.md>) | Выбор, применение, сброс и различие черновика/применённого условия; не создаётся второй набор фильтров для другого вида |

Дискретные поля фильтрации подключают [общий селект](<../../Общие компоненты/Базовые элементы/Селект/Контракт.md>); [конфигурация полей](<../../Общие компоненты/Фильтрация отчётов/Контракт.md#применения-общего-селекта>) задаёт подписи, варианты и multiple/single. Данные и DRAFT/APPLIED принадлежат текущему контексту избранного; размеры и механику дочернего контрола повторно не определять.

## Текущий локальный контекст · 4 ноября 2026

Начальный маршрут — `/preview/navigation`: section=home, tab=reports, segment=favorites, все три вида=list. NavigationPreview координирует видимые блоки, [App](<../../../references/implementation/app/App.tsx>) задаёт только технические варианты стенда. Значения ниже описывают локальную демонстрацию, не production URL, серверную схему или долговременную память.

| Состояние | Где ведётся в текущей демонстрации | Вход / изменение / сброс |
|---|---|---|
| Выбранный раздел | URL `section`; Sidebar получает current ID | Неизвестное значение даёт home; выбор пункта меняет section и закрывает открытые панели/меню. Содержимое исключённых разделов этим не включается |
| Тип содержимого и отчётный сегмент | URL `tab`, `segment`; Home передаёт выбранные ID в B10/B09 | Неизвестные значения дают reports/favorites. Смена tab закрывает overlays и снимает открытый news; смена segment закрывает overlays. Источники/AI Hub внутри Главной остаются неподключёнными |
| Вид каждого отчётного сегмента | Локальная карта Favorites/Subscriptions/Contribution | Каждый начинает с list. Ручной выбор меняет только свой вид; переходы между сегментами сохраняют его в текущем смонтированном просмотре. Root не читает `view` из URL; reload начинает локальные виды заново |
| Текущие страницы списков | Отдельные локальные индексы избранного/подписок/вклада | B17 передаёт намерение смены страницы; родитель выдаёт соответствующую порцию/total. Подписки/вклад сбрасывают внутренний scroll при смене страницы или вида; сохранение их scroll после возврата не обещается |
| Тип вклада | Локальный выбор contributors/platforms | Начальный — «Контрибьюторы». «Платформы» выбирается, но собственного содержимого нет; другая страница не достраивается |
| Категория и выбранная новость | URL `category`, `news`; H-04 задаёт смысл отбора/возврата | Неизвестная category даёт all. News ID, отсутствующий в текущей категории, не открывает другую статью: показан её список. Позиция списка хранится локально по категории; полный reload не сохраняет её |
| Режим sidebar | Локальное состояние окружения, переданное C01 | Начальный — expanded; toggle меняет только режим, не current ID. Долговременное сохранение не определено |

Состав выдачи и счётчики — собственные данные контекста: избранное10, подписки10, вклад5, новости9; категории новостей4/3/2 по H-04. Общие счётчики вкладок не подменяются длиной текущей страницы или результатом фильтра. Локальные входы demo-производителя — [reports.json](<../../Ресурсы/Срез прототипа/data/reports.json>) (`data.favorite_rows`, `data.summaries`) и [home.json](<../../Ресурсы/Срез прототипа/data/home.json>) (`data.subscriptions`, `data.contribution`, `data.news_articles`). Это чистые данные среза для замены demo-производителя, не API и не постоянные business totals. Происхождение подписок и участников дополнительно видно в [fixture подписок](<../../../references/implementation/features/subscriptions/contentFixture.ts>) и [проекции пяти людей](<../../../references/implementation/features/contributors/contentFixture.ts>); чтение этих producers не требуется для получения данных. Исходные placeholder-счётчики/PNG не меняют фактический состав.

### Видимость управляющих групп

Главная всегда передаёт вкладки типов B10 с постоянными счётчиками. Для tab=reports показаны три отчётных сегмента B09. Переключатель вида показан у избранного, а у подписок/контрибьюторов скрыт при пустом наборе; фильтр относится только к избранному. Тип вклада показан в contribution при непустом наборе участников. Для tab=news категории показаны только у непустого списка, а при чтении их место занимает собственная навигация новости. Эти условия принадлежат Главной; внутренний стиль/клавиши B09/B10/B12 не переопределяются.

### Текущие исходы действий подписок

Карточка C07 и локальная таблица подписок передают одинаковые по смыслу UI-намерения. Главная принимает идентичность подписки либо связанного отчёта; внешнее выполнение остаётся за подключаемым окружением.

| Действие / предусловие | Текущий demo-исход | Граница ответственности |
|---|---|---|
| «Отписаться» у доступной подписки | Закрываемое уведомление «Отписка не выполнена: серверные действия в демопрототип не подключены.»; состав/статус10 подписок не меняется | Реальное прекращение подписки, подтверждение, успех/ошибка и persistence не определены |
| «Напишите боту» | Закрываемое уведомление «Переход к боту не выполнен: внешний адрес в документации не определён.» | URL/вкладка и работа бота не вымышляются |
| Название связанного отчёта | Открывается паспорт именно этого ID с «Обзора», сохранён текущий исходный адрес; возврат по R-01 | Содержимое/доступность вкладок паспорта и внешний BI — у их владельцев, не у подписки |
| Уведомление показано | «Закрыть уведомление» или смена location убирает его | Это локальная обратная связь Главной, не универсальный новый toast-компонент |

Root обрабатывает open-report по той же идентичности, что передала подписка; подтверждённые метаданные берутся из общего набора. Для отчёта «Профайл МОП», присутствующего только в подписках, сохраняются его ID/подпись и исходный домен «Домен не указан»; неподтверждённые атрибуты не заполняются другим отчётом. Полнота его паспорта проверяется отдельно.

Технические `homeCase=paginated` (порция3 для подписок/вклада) и `homeCase=empty-favorites|empty-subscriptions|empty-contribution|empty-news`, а также `favoriteCase=two-pages` (порция8 для избранного) служат воспроизводимой проверке. Это состояния стенда, не продуктовые настройки пользователя или URL-гарантия.

| Вход / состояние | Значение для Главной | Внешняя граница |

Это семантические роли отображения, не backend DTO. Главная передаёт намерение выбрать сегмент/вид/объект, изменить условия или страницу; внешние маршруты, права, вычисления, сохранение и выполнение действий остаются за соответствующим окружением.

## 5. Приёмка и открытые границы

1. Начать с текущих состояний среза в «Состояния»; исходные семь подсекций, exact IDs/имена/размеры и PNG сверять как provenance с учётом поздних решений. Не принимать галерею или скрытый референс за рабочую страницу.
2. Собрать композицию через принятых владельцев общих компонентов; применить только локальные размеры/наборы из «Виды».
3. Сверить активный контекст, сегмент и вид; не подменять избранное каталогом, человека — отчётом, подписку — формой рассылки.
4. Проверить слои, независимый header таблицы, закреплённую пагинацию, тень и границы scroll/clip по конкретному source-state. Не объявлять прокрутку настроенной там, где её нет.
5. Сопоставить выбранный/применённый домен и смену вида с владельцем FL. Демо-данные не превращать в общие бизнес-правила.
6. Для новостей сохранить нативную структуру, собственные ресурсы и различие списка/чтения; demo-сценарий проверять по [H-04](<../../../context/target/Пользовательские пути/Главная.md#категории-и-навигация-чтения--решение-3-ноября-2026>), полноту материалов — по «Новости». Текущий source/PNG и историческая приёмка не подменяют новую проверку изменённого результата.
7. Проверить локальные ссылки, anchors, ресурсы и SHA256. Сравнивать рендер при тех же размерах/состоянии; функциональные действия испытывать отдельно.

Не установлены содержимое вкладок «Источники»/«AI Hub» внутри Главной, подвид «Платформы» вклада, выдача на неподготовленных production-данных, backend totals, production persistence/URL, права, реальные отписка/бот/редактирование, production-интеграция новостей, узкая адаптация и frontend mapping. Исходное перекрытие пагинации участниками остаётся отклонением макета, не целевым правилом. Самопроверка документа не заменяет приёмку координатора.
