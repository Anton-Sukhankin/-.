## 1. Граница и владельцы

Главная собирает текущий пользовательский контекст: тип содержимого, сегмент отчётов, вид списка, группы, данные и состояние фильтрации. Она не равна самостоятельному каталогу отчётов. Выбор «Избранные» не должен превращать текущий набор во все отчёты.

## 3. UI-данные и локальное состояние

| Вход / состояние | Значение для Главной | Внешняя граница |
|---|---|---|
| Текущий тип | Показаны вкладки «Отчёты», «Источники», «AI Hub», «Новости» | Собраны содержательные поверхности отчётов/новостей; содержимое «Источники»/«AI Hub» не подтверждено этой секцией |
| Контекст отчётов | «Избранные», «Мои подписки», «Вклад в каталог» | Наборы разные. Состав по правам/ролям не определяется этими счётчиками |
| Вид | Карточный или табличный для текущего сегмента | Сохранение условий избранного — по FL; межсессионное хранение не установлено |
| Список / группы | Устойчивая идентичность объекта, данные соответствующего компонента; домен и отображённое число группы, где группа показана | Не вычислять глобальный total по количеству нарисованных элементов |
| Выбранные / применённые условия | Два состояния фильтрации; индикатор и выдача по владельцу FL | Произвольные комбинации, серверная выдача и права не проектируются здесь |
| Пагинация | Текущая страница, подпись диапазона/total и размер порции как UI-значения | Примеры 9 990 / 999 / 10 — демо. Переключение компонента не доказывает замену данных |
| Новости | Идентичность новости, метка, заголовок, анонс, дата, изображение/текст, показанная текущая позиция | Производитель публикаций, read/unread и автоматическое снятие «Новое» неизвестны |

Это семантические роли отображения, не backend DTO. Главная передаёт намерение выбрать сегмент/вид/объект, изменить условия или страницу; внешние маршруты, права, вычисления, сохранение и выполнение действий остаются за соответствующим окружением.

## 5. Приёмка и открытые границы

1. Проверить все семь подсекций по реестру «Состояния», точные node IDs, имена, размеры и PNG. Не принимать галерею или скрытый референс за рабочую страницу.
2. Собрать композицию через принятых владельцев общих компонентов; применить только локальные размеры/наборы из «Виды».
3. Сверить активный контекст, сегмент и вид; не подменять избранное каталогом, человека — отчётом, подписку — формой рассылки.
4. Проверить слои, независимый header таблицы, закреплённую пагинацию, тень и границы scroll/clip по конкретному source-state. Не объявлять прокрутку настроенной там, где её нет.
5. Сопоставить выбранный/применённый домен и смену вида с владельцем FL. Демо-данные не превращать в общие бизнес-правила.
6. Для новостей сохранить нативную структуру, собственные ресурсы и различие рабочего списка/чтения.
7. Проверить локальные ссылки, anchors, ресурсы и SHA256. Сравнивать рендер при тех же размерах/состоянии; функциональные действия испытывать отдельно.

Не установлены содержимое вкладок «Источники»/«AI Hub», подвид «Платформы» вклада, произвольная выдача/условия, backend totals, persistence/URL, права, рабочие исходы открытия/отписки/редактирования/новостной навигации, узкая адаптация и frontend mapping. Для карточных подписок не настроена внутренняя прокрутка в прочитанном кадре. У применённого карточного примера пагинация скрыта; его paddingBottom0 — локальная конфигурация, а не автоматически дефект резерва. Перекрытие видимой пагинации в таблице участников зафиксировано отдельно в «Виды». Эти границы явно ограничивают интеграционную готовность. Самопроверка документа не заменяет приёмку координатора.
