## 1. Граница и владельцы

Главная собирает текущий пользовательский контекст: тип содержимого, сегмент отчётов, вид списка, группы, данные и состояние фильтрации. Она не равна самостоятельному каталогу отчётов. Выбор «Избранные» не должен превращать текущий набор во все отчёты.

| Владелец | Что Главная получает / сохраняет |
|---|---|
| [H-01…H-04](<../../../context/target/Пользовательские пути/Главная.md>) | Сквозные цели просмотра избранного, фильтрации, подписок/вклада и чтения новости. Здесь только локальные композиции и свидетельства |
| [FL-01 / FL-02](<../../../context/target/Пользовательские пути/Фильтрация отчётов.md>) | Выбор, применение, сброс и различие черновика/применённого условия; не создаётся второй набор фильтров для другого вида |
| [Требования и границы](<../../../context/target/Требования и границы.md>) | Принятая цель и ограничения продукта, включая новостные метки; наблюдение макета не заменяет решение |

## Текущий локальный контекст · 4 ноября 2026

Начальный маршрут — `/preview/navigation`: section=home, tab=reports, segment=favorites, все три вида=list. [NavigationPreview](<../../../references/implementation/app/NavigationPreview.tsx>) координирует видимые блоки, [App](<../../../references/implementation-current/app/App.tsx>) подключает технические варианты стенда. Маршруты, параметры и наборы этого подраздела относятся к локальной демонстрации.

| Состояние | Где ведётся в текущей демонстрации | Вход / изменение / сброс |
|---|---|---|
| Выбранный раздел | URL `section`; Sidebar получает current ID | Неизвестное значение даёт home; выбор пункта меняет section и закрывает открытые панели/меню. Содержимое исключённых разделов этим не включается |
| Тип содержимого и отчётный сегмент | URL `tab`, `segment`; Home передаёт выбранные ID в B10/B09 | Неизвестные значения дают reports/favorites. Смена tab закрывает overlays и снимает открытый news; смена segment закрывает overlays. Источники/AI Hub внутри Главной остаются неподключёнными |
| Вид каждого отчётного сегмента | Локальная карта Favorites/Subscriptions/Contribution | Каждый начинает с list. Ручной выбор меняет только свой вид; переходы между сегментами сохраняют его в текущем смонтированном просмотре. Root не читает `view` из URL; reload начинает локальные виды заново |
| Текущие страницы списков | Отдельные локальные индексы избранного, подписок и вклада | Общая панель передаёт намерение смены страницы. Родитель подаёт порцию, размер страницы и полный размер результата. При смене вида остаются индекс и те же объекты. Подписки и вклад при смене страницы или вида прокручиваются к началу. Применение, сброс и сортировка избранного возвращают его на первую страницу |
| Тип вклада | Локальный выбор contributors/platforms | Начальный — «Контрибьюторы». «Платформы» выбирается, но собственного содержимого нет; другая страница не достраивается |

Позиция списка хранится локально по категории до перезагрузки |
| Режим sidebar | Локальное состояние окружения, переданное C01 | Начальный — expanded; toggle меняет только режим, не current ID. Долговременное сохранение не определено |

Счётчик вкладки «Отчёты» равен полному исходному набору избранного. Счётчики трёх сегментов равны полным исходным наборам избранного, подписок и вклада. Числа в переключателях сохраняются при переходе на другую страницу и при фильтрации избранного. Диапазон и число результатов в пагинации рассчитываются по отфильтрованному набору. Вкладка «Новости» показывает полное число новостей, а её сегменты — размер каждой категории. Вкладки «Источники» и «AI Hub» не показывают счётчики.

Для проверки страниц прототип по умолчанию расширяет три отчётных набора до 35 демозаписей. `paginationDemo=0` оставляет базовые наборы 10, 10 и 9 соответственно. Данные базовых подписок и участников ведут [fixtures подписок](<../../../references/implementation/features/subscriptions/contentFixture.ts>) и [участников](<../../../references/implementation-current/features/contributors/contentFixture.ts>). [Новости](<Новости.md#1-список-и-карточка>) ведут отдельный набор. Данные в [JSON среза 4 ноября](<../../Ресурсы/Срез прототипа/README.md>) сохраняют состояние на дату снимка.

### Текущие исходы действий подписок

Карточка C07 и локальная таблица подписок передают одинаковые по смыслу UI-намерения. Главная принимает идентичность подписки либо связанного отчёта; внешнее выполнение остаётся за подключаемым окружением.

| Действие / предусловие | Текущий demo-исход | Граница ответственности |
|---|---|---|
| «Отписаться» у доступной подписки | Закрываемое уведомление «Отписка не выполнена: серверные действия в демопрототип не подключены.»; состав/статус10 подписок не меняется | Реальное прекращение подписки, подтверждение, успех/ошибка и persistence не определены |
| «Напишите боту» | Закрываемое уведомление «Переход к боту не выполнен: внешний адрес в документации не определён.» | URL/вкладка и работа бота не вымышляются |
| Название связанного отчёта | Открывается паспорт именно этого ID с «Обзора», сохранён текущий исходный адрес; возврат по R-01 | Содержимое/доступность вкладок паспорта и внешний BI — у их владельцев, не у подписки |
| Уведомление показано | «Закрыть уведомление» или смена location убирает его | Это локальная обратная связь Главной, не универсальный новый toast-компонент |

Root обрабатывает open-report по той же идентичности, что передала подписка; подтверждённые метаданные берутся из общего набора. Для отчёта «Профайл МОП», присутствующего только в подписках, сохраняются его ID/подпись и исходный домен «Домен не указан»; неподтверждённые атрибуты не заполняются другим отчётом. Полнота его паспорта проверяется отдельно.

Для пустых состояний стенд поддерживает `homeCase=empty-favorites|empty-subscriptions|empty-contribution|empty-news`. Для сверки старых снимков сохранены входы `homeCase=paginated` с порцией 3 для подписок и вклада и `favoriteCase=two-pages` с порцией 8 для избранного. Актуальный размер страницы и размещение панели заданы в [применении пагинации](<Виды.md#применение-пагинации-b17>).

## 3. UI-данные и локальное состояние

| Вход / состояние | Значение для Главной | Внешняя граница |
|---|---|---|
| Текущий тип | Показаны вкладки «Отчёты», «Источники», «AI Hub», «Новости» | Собраны содержательные поверхности отчётов/новостей; содержимое «Источники»/«AI Hub» не подтверждено этой секцией |
| Контекст отчётов | «Избранные», «Мои подписки», «Вклад в каталог» | Наборы разные. Состав по правам/ролям не определяется этими счётчиками |
| Вид | Карточный или табличный для текущего сегмента | Сохранение условий избранного — по FL; межсессионное хранение не установлено |
| Список / группы | Устойчивая идентичность объекта, данные соответствующего компонента; домен и отображённое число группы, где группа показана | Не вычислять глобальный total по количеству нарисованных элементов |
| Выбранные / применённые условия | Два состояния фильтрации; индикатор и выдача по владельцу FL | Произвольные комбинации, серверная выдача и права не проектируются здесь |
| Пагинация | Текущая страница, диапазон, число результатов и размер порции | Серверный источник полного числа результатов не определён |
| Новости | Идентичность новости, метка, заголовок, анонс, дата, обложка и блоки статьи | Производитель публикаций, read/unread и автоматическое снятие «Новое» неизвестны |

Это семантические роли отображения, не backend DTO. Главная передаёт намерение выбрать сегмент/вид/объект, изменить условия или страницу; внешние маршруты, права, вычисления, сохранение и выполнение действий остаются за соответствующим окружением.
