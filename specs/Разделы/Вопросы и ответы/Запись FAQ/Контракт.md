# Запись FAQ

Входные данные записи — стабильный идентификатор, текст вопроса и текст ответа. В списке запись использует общий [аккордеон](<../../../Общие компоненты/Аккордеон/Контракт.md>) в варианте `report`. Вопрос занимает заголовок. Ответ занимает тело. [Параметры локальных отступов](<Параметры.yaml>) · [Эталон раскрытой записи](<../assets/faq-open-1440.png>).

При входе в FAQ записи свёрнуты. Заголовок, Enter или Space переключают раскрытие выбранной записи. Раскрытие каждой записи независимо. При переключении на «Мои вопросы» и обратно остаётся раскрытым ответ записи, которую не удалил из списка локальный поиск или смена страницы. Для входа с совпадением действует [переход из Навигатора](<../Контракт.md#вход-из-навигатора>).

| Условие | Выдача |
|---|---|
| Локальный запрос содержит текст | Список оставляет записи, в вопросе или ответе которых есть введённая подстрока. Для сопоставления игнорируются регистр, пробелы по краям запроса и различие е/ё. Полное число в сегменте сохраняется. Число совпадений объявляется как доступный статус. |
| Запрос без текста | Список показывает полный набор с учётом пагинации. |
| Записи существуют, совпадений нет | [Пустое состояние рабочего списка](<../../../Общие компоненты/Базовые элементы/Пустое состояние/Контракт.md#пустое-состояние-рабочего-списка>) «Ничего не найдено», подпись «Измените запрос или вернитесь ко всем вопросам FAQ.». Кнопка «Очистить запрос» восстанавливает выдачу и фокус поля. [Эталон](<../assets/faq-no-results-1440.png>). |
| Исходный набор FAQ пуст | Пустое состояние «Вопросов пока нет», подпись «Здесь появятся ответы на частые вопросы о каталоге.». Поиск и пагинация скрыты. В текущем стенде отсутствует отдельный набор для этого состояния. |

Содержание справки задаёт переданный набор FAQ. Для локального воспроизведения используйте [контрольные данные](<../Контрольные данные.json>).
