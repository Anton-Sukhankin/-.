# Панель управления раздела «Вопросы и ответы»

Панель располагается над выдачей в [рабочей области раздела](<../Контракт.md#сборка-раздела>). В верхней строке идут [сегмент-контрол](<../../../Общие компоненты/Базовые элементы/Сегмент-контрол/Контракт.md>), гибкое поле поиска высотой 40 px и кнопка «Задать вопрос» с иконкой слева. Для поиска используйте локальный вариант из [параметров панели](<Параметры.yaml>) и [общий фокус поля](<../../../Общие компоненты/Базовые элементы/Поле ввода/Контракт.md#форма-и-фокус--решение-7-ноября-2026>). В узкой рабочей области элементы располагаются вертикально. При пустом исходном наборе активного сегмента поле поиска скрыто, сегмент-контрол и кнопка доступны.

| Элемент | Правило |
|---|---|
| Сегменты «FAQ» и «Мои вопросы» | Активен один сегмент. Число рядом с названием равно размеру полного исходного набора сегмента. Локальный запрос, статус и страница это число не изменяют. |
| Поле в FAQ | Подсказка «Поиск в FAQ». Поиск применён к [вопросам и ответам](<../Запись FAQ/Контракт.md>). |
| Поле в «Моих вопросах» | Подсказка «Поиск по темам и сообщениям». Поиск применён к [обращениям](<../Карточка обращения/Контракт.md>). |
| Крестик поля | Видим при заполненном поле. Имена действий «Очистить поиск в FAQ» и «Очистить поиск по обращениям». Очистка возвращает фокус в поле и сбрасывает страницу. Статус «Моих вопросов» сохраняется. |
| Нижняя строка в «Моих вопросах» | При наличии обращений показывает «Все», «Новый», «В работе», «Решён», «Закрыт». Исходно активен чип «Все». Активен ровно один чип. |
| Счётчики чипов | «Все» показывает число совпадений по локальному запросу до применения статуса. Остальные чипы показывают число таких совпадений с соответствующим статусом. Ноль видим, выбор чипа с нулём доступен. |
| Цвет счётчиков | Чип и сегмент используют один [счётчик B12](<../../../Общие компоненты/Базовые элементы/Счётчик/Контракт.md>) с одинаковой индикацией выбора. |

При переключении сегмента шапка, верхняя строка панели и кнопка сохраняются в дереве и не мерцают. Входящий список меняется плавно. Нижняя строка чипов раскрывается в «Моих вопросах» с обращениями и сворачивается в FAQ. Скрытая строка недоступна для фокуса. При включённом уменьшении движения раскрытие и смена списка происходят без анимации.
