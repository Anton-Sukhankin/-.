## Сборка

| Область | Состав и размещение |
|---|---|
| Заголовок раздела | Те же заголовок, описание и [панель поиска и фильтрации](<Панель поиска и фильтрации/Контракт.md>), что в каталоге. Над решением сохраняется уровень заголовка раздела. Хлебные крошки в этой компоновке отсутствуют. |
| Шапка решения | Слева [круглая кнопка возврата](<../../Общие компоненты/Базовые элементы/Кнопка/Контракт.md>) с шевроном влево, затем название. Зазор задаёт `header-title-gap`. Справа по порядку идут «Открыть инструмент», «Инструкции», редактирование и закладка. Закладка есть у каждого решения. Остальные действия и перенос определяются данными и доступной шириной. |
| Содержимое | Под шапкой слева блоки «Назначение», «Решаемые задачи», «Пример запроса». Справа [паспорт решения](<Паспорт решения/Контракт.md>). Если отдельных абзацев назначения нет, используется краткое описание. Задачи и пример выводятся при наличии соответствующих данных. |
| Навигация | [Список текущей выдачи](<Навигация по решениям/Контракт.md>) справа, текущий пункт отмечен. После достижения порога stack-navigation-max список расположен под карточкой. |
| Узкий корпус | Пороги относятся к внутренней ширине всей рабочей области AI Hub. До 1080 px включительно паспорт идёт под обзором. До 650 px включительно список решений и панель действий также переносятся вниз. [Точные параметры](<Параметры.yaml>). |

Название решения и абзацы назначения поддерживают подсветку совпадения общего Навигатора. После очистки запроса выделение снимается по [контракту Навигатора](<../../Общие компоненты/Поиск и навигатор/Контракт.md>). Статистика просмотров и отметок «Нравится» относится к [карточке каталога](<Карточка решения/Контракт.md>).

## Прокрутка и переходы

- Заголовок раздела, его описание, панель фильтрации и шапка открытого решения остаются на месте. Тело решения и список решений прокручиваются независимо при переполнении. При достижении края каждой области прокрутка в оболочку не передаётся.
- При открытии решения из каталога создаётся запись истории. Фокус получает заголовок решения. Если каталог был прокручен и его описание свёрнуто, при открытии решения описание снова становится видимым. Круглая кнопка возврата и браузерный Back возвращают исходную выдачу, её страницу и прокрутку. Фокус возвращается на название открывавшей карточки, когда оно доступно.
- Из каталога и при прямом входе имя кнопки — «Вернуться в каталог AI Hub». При входе из подборки на «Главной» имя меняется на «Вернуться к избранным решениям AI Hub». Нажатие возвращает в ту же подборку с восстановлением позиции и фокуса по [правилам «Главной»](<../Главная/Контракт.md#избранные-источники-и-решения-ai-hub>).
- Выбор другого решения из списка заменяет ID в текущей записи истории. Анимация затрагивает только карточку решения, её содержимое открывается с начала, позиция правого списка и фокус на выбранном пункте сохраняются. Вход из каталога и возврат анимируют изменившуюся нижнюю область, оставляя общую шапку на месте. Действует системная настройка уменьшения движения.
- При прямом входе и входе через общий Навигатор кнопка возврата удаляет ID решения из текущего URL и сохраняет условия каталога в этой записи. Неизвестный ID показывает каталог с сообщением «Решение не найдено. Показан каталог.» и действием «К каталогу».
- При изменении условий открытое решение остаётся на экране. Если его исключила фильтрация, над обзором показывается «Выбранное решение не входит в текущую выдачу». Правый список следует изменившейся выдаче.
- Закладка обновляет выбранность этого ID в каталоге и на «Главной». Действие с адресом открывает ссылку. При отсутствии адреса появляется уведомление «Адрес для действия ‹название› не предоставлен.». Если запись допускает редактирование, кнопка в прототипе показывает «Редактор решения не подключён.».
