# Карточка решения AI Hub

Позиция [каталога](<../Каталог.md>). [Параметры.yaml](<Параметры.yaml>) ведёт локальные размеры. [Кадр обычного состояния](<../Изображения/ai-hub-1440.png>) и [кадр наведения](<../Изображения/solution-card-hover.png>) сняты на первом решении каталога.

| Зона | Состав и правила |
|---|---|
| Шапка | Теги типа и статуса. Тег «Можно переиспользовать» выводится при признаке переиспользования. При его отсутствии признак «ИИ-пятница» даёт тег «ИИ-пятница». Тип «ИИ-помощник функций» фиолетовый, другие типы синие. «Демо» использует нейтральный тон статуса, прочие статусы зелёный. |
| Тело | Название, статистика просмотров и отметок «Нравится» в одной строке компоновки, затем «Домен · …» и описание до двух строк. Полное описание доступно [при фактическом обрезании](<../../../Общие компоненты/Текстовые подсказки/Контракт.md>). Значения статистики поступают из данных позиции. |
| Футер | По порядку «Запись ИИ-пятницы», «Инструкции», «Открыть инструмент», если соответствующее действие присутствует во входных данных. Справа круглая закладка с aria-pressed. Строка действий может переноситься при сужении. |

Клик по любой свободной зоне карточки, включая шапку и свободное место футера, открывает соответствующее решение. С клавиатуры решение открывает кнопка с названием. Кнопки и ссылки футера имеют свои цели и сохраняют каталог открытым при локальном действии. Закладка меняет локальное состояние решения. Внешняя ссылка требует адреса из данных. При отсутствии адреса кнопка показывает уведомление о недоступности в прототипе, которое можно закрыть. Состав бизнес-действий и назначение внешних адресов требуют подтверждения владельца продукта.

Карточка использует [общую поверхность и ховер](<../../../Общие компоненты/Карточки отчётов/Контракт.md#название-и-иконка-при-наведении>). При наведении на карточку название становится синим, включая наведение на свободную область футера. Значки статистики и внешнего действия остаются частью своих элементов. [Сценарий проверки зон нажатия](<../Сценарии и эталоны.md#каталог>).
