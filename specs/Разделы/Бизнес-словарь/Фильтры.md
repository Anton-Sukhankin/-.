# Фильтры Бизнес-словаря

Этот ряд полей используется на вкладках «Все» и «Термины». На вкладке «Домены» фильтров нет. Варианты и режимы ниже относятся к демонстрационным данным прототипа.

| Поле | Режим | Варианты и условие совпадения |
|---|---|---|
| «Тип» / «Тип термина» | Одиночный | Типы терминов из текущего среза вкладки. Во «Все» значение «Домен» соответствует записям справочника, входящим в этот срез |
| «Домен» | Множественный | Домен, назначенный термину. Во «Все» домен также совпадает со своей записью справочника. «Без домена» соответствует только терминам с отсутствующим назначением |
| «Статус» | Одиночный | Фильтрует термины по статусу |
| «Владелец» | Одиночный | Фильтрует термины по подтверждённому владельцу. «Не указан» соответствует терминам с отсутствующим владельцем |

Варианты строятся по доступным записям вкладки до применения фильтров. Изменения действуют сразу. В «Домене» значения объединяются по «или», между полями применяется «и». Выбор нового значения одиночного поля заменяет прежнее и закрывает список. «Все» в одиночном поле, очистка домена или снятие последнего флажка снимают ограничение только этого поля. Вкладки сохраняют отдельные наборы в адресе прототипа. Если прежний адрес содержит несколько значений одиночного поля, при открытии действует первое допустимое значение.

Раскрытие использует общий список значений B04. В словаре поле «Поиск значений» появляется, когда полный список вариантов превышает семь полных строк. Ввод ограничивает только список вариантов. Сокращение списка до одной или нуля строк не скрывает поле поиска. Escape закрывает список и возвращает фокус к полю. Теги и переключение между видимыми и скрытыми значениями — по [B04](<../../Общие компоненты/Базовые элементы/Селект/Контракт.md#теги-множественного-выбора--решение-4-ноября-2026>).

На вкладках «Все» и «Термины» между селектами 8 px. При четырёх колонках ширина всей сетки равна `calc((100% - 48px) * 0.8 + 24px)` от ширины панели фильтров. При ширине окна до 800 px включительно сетка перестраивается в две колонки и занимает `calc((100% - 16px) * 0.8 + 8px)`. Раскрытый список повторяет внешнюю ширину своего селекта.

При выборе хотя бы одного значения справа от селектов появляется кнопка «Сбросить» высотой 40 px, как в каталоге метрик. Если места рядом с селектами не хватает, кнопка переносится ниже и выравнивается по правому краю панели. Она очищает все поля активной вкладки, закрывает открытый список, возвращает фокус к первому селекту и обновляет выдачу. Выдача активной вкладки возвращается на первую страницу. Фильтры соседней вкладки сохраняются. [Браузерная проверка](<../../../references/verification/tests/dictionary.spec.ts>).

Домены учитывают фильтры «Тип» и «Домен». Статус и владелец применяются только к терминам. Например, при выборе «Утверждён» в демонаборе сверху показаны 8 доменов, ниже 4 термина, общий счётчик равен 12. Пустые группы скрываются. При нуле результатов показано «По выбранным фильтрам ничего не найдено.». После снятия фильтров счётчик возвращается к размеру доступного набора вкладки.

Если переход из Навигатора ведёт к термину вне текущих условий, на вкладке «Термины» показывается только найденный термин с пояснением. Выбранные фильтры сохраняются. Следующее изменение фильтра возвращает обычную отфильтрованную выдачу. Переход к домену открывает страницу с ним на вкладке «Домены» и выделяет совпадение в названии. Оба результата входят в чип «Бизнес-словарь» по [контракту Навигатора](<../../Общие компоненты/Поиск и навигатор/Контракт.md>).

Параметры адреса имеют вид `dictionary.<вкладка>.<поле>`. Вкладка — `all` или `terms`, поле — `type`, `domain`, `status` или `owner`. Обычное значение записывается как `value:<подпись варианта>`. Для «Без домена» и «Не указан» используется `missing`, для типа «Домен» на «Все» — `domain-row`. Для нескольких доменов параметр повторяется. Неизвестные значения игнорируются, повторы удаляются.
