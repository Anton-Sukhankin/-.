# Строка домена

Пассивная строка списка во вкладке «Домены» и группе «Домены» вкладки «Все». [Раздел](<Контракт.md>) передаёт ID и название. Строка показывает иконку домена и название. Иконка декоративная, без круглой подложки, размещена в прозрачном слоте. Название переносится при нехватке места. Навигатор открывает страницу с нужным доменом и подсвечивает совпадение в названии. Строка служит для чтения в списке.
