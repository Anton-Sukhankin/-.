Документы описывают готовые экраны и действия из границ разделов. Задачи и неготовые ветви реализуются после отдельного согласования. Демонстрационные данные служат для сверки экранов.

Файлы в references подтверждают происхождение отдельных параметров и сценариев. Открывайте их, когда нужно проверить конкретное утверждение. Архивные кадры используются только по назначению, указанному у владельца компонента.
