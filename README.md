# Каталог данных · контекст для фронтенд-разработки

Поставка 5 ноября 2026. Начните с [AGENTS.md](AGENTS.md) и [маршрутов по четырём разделам](specs/Обзор.md). Откройте контракт порученного интерфейса, его параметры, применимый пользовательский сценарий и соответствующий кадр.

| Раздел | Точка входа |
|---|---|

| Отчёты | [Каталог](<specs/Разделы/Отчёты/Контракт.md>) · [паспорт](<specs/Разделы/Отчёты/Паспорт/Контракт.md>) |

Общие компоненты подключаются из контрактов потребителей. Задачи, Бизнес-словарь, AI Hub, Справочники ИС и общий раздел «Вопросы и ответы» вне поставки. Если их названия видны на снимке общего меню, это контекст оболочки. Вопросы внутри паспорта отчёта описываются в границе самого паспорта.

[Кадры и демонстрационные данные](<specs/Ресурсы/Срез прототипа/README.md>) фиксируют условия воспроизведения. Для принятых уточнений после среза действуют кадры и правила у владельцев, например [поиск](<specs/Общие компоненты/Поиск и навигатор/Источники вида.md#кадры-принятой-реализации>) и [теги селекта](<specs/Общие компоненты/Базовые элементы/Селект/Контракт.md#теги-множественного-выбора--решение-4-ноября-2026>). Используйте утверждённое правило при расхождении со снимком. Ссылки Figma и Paper фиксируют происхождение, локальные эталоны доступны из пакета.

[PACKAGE.json](PACKAGE.json) содержит полный перечень переданных файлов и их контрольные суммы. `references/` содержит адресные материалы для сверки. Реализация ведётся в рабочем репозитории команды.
